# 메모리

> 지금 실행 중인 프로그램과 데이터를 잠깐 올려두는 빠른 작업 공간. 보통 RAM을 말한다.

## 설명
- 프로그램을 실행하면 [[저장장치]]에 있던 프로그램이 메모리로 올라오고, [[CPU]]는 메모리에서 꺼내 처리한다.
- 빠르지만 휘발성이다. 전원이 꺼지면 내용이 사라진다.
- 용량이 작다. 보통 8~32GB (저장장치는 256GB~수 TB).
- 메모리가 꽉 차면 [[운영체제]]가 저장장치 일부를 임시로 빌려 쓰는데(가상 메모리), 저장장치는 훨씬 느려서 컴퓨터가 버벅인다.

## 비유
조리대. 넓을수록 재료를 많이 펼쳐놓고 여러 요리를 동시에 할 수 있다. 영업이 끝나면(전원을 끄면) 다 치운다.

## 헷갈리기 쉬운 점
- 일상에서는 "메모리"를 저장 용량 뜻으로 쓰기도 하지만(폰 "메모리 부족"), 컴퓨터 구조에서 메모리는 보통 RAM이다.
- 저장 안 한 문서는 아직 메모리에만 있고 저장장치에 안 써졌기 때문에, 컴퓨터가 꺼지면 날아간다.

## 웹 개발에서는
- 크롬 탭은 하나하나가 메모리를 차지하기 때문에, 탭을 많이 열면 느려진다.
- VS Code에서 고친 내용은 Ctrl+S 전까지 메모리에만 있다. 저장 안 하면 개발 서버도 [[브라우저]]도 바뀐 걸 모른다. 탭 이름 옆 ● 표시가 "아직 저장 안 됨".
- 웹페이지 JavaScript의 변수도 방문자 브라우저의 메모리에 있다. 그래서 새로고침하면 사라진다. 오래 남기려면 따로 저장하는 곳(데이터베이스 등)이 필요하다.

## 관련 개념
- [[저장장치]]: 메모리와 짝. 느리지만 꺼져도 남는 곳
- [[CPU]]: 메모리에서 꺼내 처리하는 쪽
- [[프로세스]]: 메모리에 올라와 실행 중인 프로그램
