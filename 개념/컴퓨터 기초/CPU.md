# CPU

> 프로그램의 명령을 하나씩 실행하는 컴퓨터의 두뇌. 중앙처리장치(Central Processing Unit).

## 설명
- CPU가 할 줄 아는 건 더하기, 비교하기, 값 옮기기 같은 아주 단순한 명령뿐이다. 대신 1초에 수십억 번 처리해서 복잡한 일을 하는 것처럼 보인다. 속도 단위 GHz는 1초에 10억 번 단위로 박자를 친다는 뜻.
- CPU는 0과 1로 된 [[기계어]]만 이해한다. 사람이 쓴 코드는 기계어로 바뀌어야 실행된다 → [[프로그램]]
- 코어: CPU 안의 실행 단위. 코어가 여러 개면 여러 일을 실제로 동시에 처리한다.
- [[저장장치]]는 너무 느리기 때문에, CPU는 저장장치에서 바로 일하지 않고 [[메모리]]에 올라온 것을 가져와 처리한다.

## 비유
주방에서 실제로 칼질하고 볶는 요리사. 요리사(코어)가 많을수록 동시에 여러 요리를 한다.

## 헷갈리기 쉬운 점
- 컴퓨터가 '생각'한다기보다, 정해진 명령을 엄청 빨리 따라 하는 것이다.
- 작업 관리자의 CPU 사용률 100% = 요리사들이 쉴 틈이 없는 상태. 다른 일이 밀려서 버벅인다.

## 웹 개발에서는
- [[개발 서버]] 켜기, [[빌드]](`npm run build`)처럼 계산이 많은 작업은 내 컴퓨터의 CPU를 쓴다.
- 웹사이트의 JavaScript와 애니메이션은 **방문자 컴퓨터**의 CPU·GPU로 돌아가기 때문에, 효과가 무거운 웹은 방문자 노트북의 팬을 돌게 한다.
