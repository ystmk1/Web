# 프로그램

> 컴퓨터가 할 일을 순서대로 적어둔 명령의 묶음. 실행하기 전에는 저장장치에 있는 파일일 뿐이다.

## 설명
- 실행하면 [[운영체제]]가 프로그램을 [[메모리]]에 올리고, [[CPU]]가 명령을 하나씩 실행한다. 이렇게 실행 중인 상태를 [[프로세스]]라고 한다.
- 사람이 쓰는 코드(소스 코드)와 CPU가 이해하는 기계어는 다르다. 그래서 번역이 필요한데, 방식이 크게 두 가지다.
  - 미리 통째로 번역해서 실행 파일로 만들어 둔다 ([[컴파일러|컴파일]]). 예: Windows의 .exe
  - 미리 만들어두지 않고, 실행하는 쪽이 코드를 받아 그 자리에서 기계어로 바꿔가며 실행한다. **[[JavaScript]]가 이쪽**이다. 브라우저나 Node.js 안의 JavaScript 엔진이 이 일을 한다.

## 비유
레시피. 종이에 적혀 있기만 하면 아무 일도 안 일어나고, 누가 보고 요리를 시작해야 의미가 생긴다.

## 헷갈리기 쉬운 점
- 프로그램 = 앱 = 애플리케이션. 거의 같은 말이다. 폰에서는 앱, PC에서는 프로그램이라고 부르는 경향이 있을 뿐.
- 프로그램(파일)과 [[프로세스]](실행 중)는 다르다.
- 코드 자체는 그냥 글자로 된 텍스트 파일이다. 메모장으로도 열린다.

## 웹 개발에서는
- [[브라우저]](크롬)도 프로그램이다. 웹사이트의 HTML·CSS·JavaScript 파일을 브라우저가 받아서 화면을 그리고 실행한다.
- 그래서 웹사이트는 설치 없이 주소만 열면 실행되는 프로그램처럼 볼 수 있다. 방문자의 브라우저가 그때그때 받아서 돌린다.
- Node.js: 브라우저 밖, 내 컴퓨터에서 JavaScript를 실행해주는 프로그램. `npm`은 Node.js와 같이 설치되는 프로그램이다.
