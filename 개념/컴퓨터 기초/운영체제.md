# 운영체제

> 하드웨어를 관리하고, 그 위에서 프로그램들이 돌아갈 수 있게 해주는 바닥 소프트웨어. OS(Operating System).

## 설명
컴퓨터를 켜면 가장 먼저 실행되고, 끌 때까지 계속 돈다.

```
나 (클릭, 타이핑)
 ↓
프로그램: 크롬, VS Code, 피그마
 ↓  "파일 열어줘", "화면에 그려줘", "인터넷 연결해줘"
OS: Windows, macOS, Linux
 ↓  드라이버를 통해 실제 기계에 명령
하드웨어: CPU, RAM, SSD, 그래픽카드
```

프로그램은 하드웨어를 직접 만지지 않고 OS에게 부탁한다(시스템 콜). 그래서 피그마는 내 그래픽카드가 어느 회사 것인지 몰라도 화면을 그릴 수 있다. OS가 프로그램에 열어둔 이 부탁 창구도 일종의 [[API]]다. 부탁하는 방법이 OS마다 달라서, 같은 앱도 Windows용(.exe)과 Mac용(.app)이 따로 있다 → [[네이티브 앱]]

### 하는 일
| 하는 일 | 예 |
|---|---|
| 프로그램 실행·관리 | [[프로그램]]을 [[메모리]]에 올려 [[프로세스]]로 만들고, [[CPU]] 시간을 번갈아 나눠줌. 음악 들으면서 피그마 켜두기 |
| 메모리 관리 | 프로그램마다 RAM 자리를 나눠주고 서로 침범 못 하게 막음 |
| 파일 관리 | [[저장장치]] 안의 폴더 구조, 파일 이름, 저장 위치 (파일 시스템) |
| 장치 관리 | 마우스, 프린터, 그래픽카드를 **드라이버**라는 작은 프로그램으로 다룸 |
| 보안·권한 | 누가 어떤 파일을 열 수 있는지 정함. "이 앱이 변경하도록 허용할까요?" |
| 네트워크 | 인터넷 연결, 프로그램마다 [[포트]] 번호 나눠주기 |
| 화면 | 바탕화면, 창, 작업표시줄 (GUI) |

### 대표적인 OS
| OS | 주로 쓰는 곳 | 특징 |
|---|---|---|
| Windows | 일반 PC | 가장 많이 쓰는 PC용 OS. Microsoft |
| macOS | 맥 | Apple. 안쪽 구조가 Linux와 같은 계열(Unix)이라 개발 명령어가 비슷함 |
| [[리눅스\|Linux]] | 서버, 개발 환경 | 무료·오픈소스. 인터넷 서버 대부분이 Linux. Ubuntu 같은 여러 배포판이 있음 |
| iOS / Android | 스마트폰 | iOS는 Apple, Android는 Google (Android 안쪽도 Linux) |

### 안쪽 구조: 커널과 셸
- **커널(Kernel)**: OS의 핵심. 하드웨어를 실제로 다루는 부분이라 눈에 보이지 않는다.
- **셸(Shell)**: 사람이 입력한 글자 명령을 해석해서 OS에 전달하는 프로그램. PowerShell, zsh, bash가 셸이고, 이 셸을 띄워서 글자를 입력하는 창이 [[터미널]]이다.

| OS | 기본 셸 |
|---|---|
| Windows | PowerShell, CMD |
| macOS | zsh |
| Linux | bash 등 |

## 비유
레스토랑의 매니저. 주문을 배분하고, 조리대 자리를 정해주고, 출입을 관리한다. 요리사(CPU)가 아무리 뛰어나도 매니저가 없으면 주문이 뒤엉킨다. OS는 여러 프로그램이 한 컴퓨터를 싸우지 않고 나눠 쓰게 해주는 관리자다.

## 헷갈리기 쉬운 점
- OS도 소프트웨어의 한 종류지만, 다른 프로그램이 돌아갈 바탕이 되는 특별한 소프트웨어다.
- 터미널은 OS 그 자체가 아니라, OS에게 글자로 명령하는 창구 프로그램이다.
- 에러가 났다고 설치가 잘못된 게 아니라, OS가 권한으로 문을 잠가둔 것일 때가 많다.

## 웹 개발에서는
웹사이트 코드는 같아도, 그 코드를 설치하고 실행하는 환경은 OS마다 다르다. 그래서 설치 안내가 Windows용, Mac용으로 나뉜다.

| 차이 | Windows | macOS / Linux |
|---|---|---|
| 경로 구분자 | `C:\Users\이름\project` (역슬래시) | `/Users/이름/project` (슬래시). 웹 주소와 코드 안 경로는 항상 `/` |
| 파일 이름 대소문자 | 기본적으로 구분 안 함 | macOS는 기본 구분 안 함, **Linux는 구분함** |
| 터미널 | PowerShell 문법 | bash·zsh 문법 |
| 프로그램 설치 도구 | 설치 파일(.exe), winget | macOS는 Homebrew, Linux는 apt 등 |
| 줄바꿈 문자 | CRLF | LF (이 차이 때문에 Git이 "LF will be replaced by CRLF" 경고를 띄움) |
| 스크립트 실행 | 기본적으로 차단되는 경우가 있음 | 실행 권한(`chmod`)이 필요할 때가 있음 |
| 단축키 | Ctrl | Cmd |

- **서버는 대부분 Linux**라서, 내 컴퓨터에선 되는데 서버에선 안 되는 일이 생긴다. 대표적인 게 `Logo.png`와 `logo.png`처럼 대소문자만 다른 파일 이름 → [[2026-10-17 로컬에선 되는데 배포하면 안 되는 이유]]
- 폰트, 스크롤바, 버튼 같은 기본 부품 모양도 OS를 따라가서 같은 웹이 다르게 보인다 → [[크로스 브라우징]]
- **WSL(Windows Subsystem for Linux)**: Windows 안에서 Linux를 같이 돌리는 기능. 서버와 같은 환경에서 개발하고 싶을 때 쓴다. 입문 단계에서는 꼭 필요하지 않다.
