# 컴퓨터 기초

웹을 배우기 전에 깔고 가는 바탕. 컴퓨터가 어떤 부품으로 이루어져 있고, 운영체제와 프로그램이 그 위에서 어떻게 일하는지.

← [[Web Workshop 홈]]

## 개념
읽는 순서대로.
- [[하드웨어]]: 손으로 만질 수 있는 부품 전부
  - [[CPU]]: 명령을 실행하는 두뇌
  - [[메모리]]: 지금 작업 중인 것을 올려두는 작업대 (RAM)
  - [[저장장치]]: 꺼져도 파일이 남는 창고 (SSD)
- [[운영체제]]: 하드웨어를 관리하고 프로그램에게 나눠주는 매니저 (OS)
  - [[리눅스]]: 서버 대부분이 쓰는 오픈소스 OS
- [[프로그램]]: 할 일을 적어둔 명령의 묶음 (= 앱)
  - [[프로세스]]: 실행 중인 프로그램
  - [[네이티브 앱]]: 특정 OS 전용으로 만든 앱
