# 컴포넌트

> 화면을 이루는 재사용 가능한 조각. 구조(마크업)와 동작(JS)을 한 덩어리로 묶는다.

## 설명
- 헤더, 카드, 버튼처럼 화면을 조각으로 나눠 따로 만든다.
- 한 번 만든 조각은 `<Card />`처럼 이름으로 불러 여러 번 쓴다.
- 조각마다 다른 값을 넘길 수 있다. 예: `<Card title="작업 1" />`. 이 값을 props라고 한다.

## 비유
피그마 컴포넌트. 메인 컴포넌트를 고치면 모든 인스턴스가 바뀌고, 인스턴스마다 텍스트 같은 속성만 바꾼다.

## 헷갈리기 쉬운 점
- 컴포넌트는 페이지가 아니다. 페이지 하나가 여러 컴포넌트로 이루어진다.
- 컴포넌트 이름은 대문자로 시작한다. `<Card />`는 내가 만든 것, `<div>`는 HTML 태그다.

## 웹 개발에서는
- [[React]]는 화면을 컴포넌트 단위로 만든다. 컴포넌트는 [[JSX·TSX]]로 쓴다.
- HTML만 쓰면 같은 헤더를 페이지 파일마다 복사해야 한다. 컴포넌트로 만들면 한 곳만 고치면 된다.
