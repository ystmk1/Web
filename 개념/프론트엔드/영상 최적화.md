# 영상 최적화

> 웹에 영상을 넣을 때 느려지지 않게 하는 방법들. 핵심은 "직접 올릴지, 전문 서비스에 맡길지"를 먼저 정하는 것.

## 설명
웹에 영상을 넣는 방법은 두 가지다.
- **직접 호스팅**: `<video src="/intro.mp4">` 처럼 영상 파일을 사이트에 직접 올려서 재생. 짧고 가벼운 장식용 루프에 적합.
- **외부 서비스 임베드**: YouTube·Vimeo·Cloudflare Stream 같은 전용 서비스에 올리고 `<iframe>`으로 불러오기. 긴 영상, 품질이 중요한 콘텐츠에 적합.

## 느려지지 않게 하는 방법
- **파일 자체를 작게**: 해상도를 낮추고(720p 안팎) H.264(mp4)로 압축. 배경 루프는 몇 MB 이내로.
- **poster 이미지**: `<video poster="/thumb.jpg">` — 영상이 로드되기 전 썸네일을 먼저 보여줘서 화면이 비지 않게 한다.
- **preload="metadata"**: 영상 전체가 아니라 길이·크기 정보만 먼저 받는다.
- **화면에 보일 때만 로드**: `loading="lazy"`나 Intersection Observer로 스크롤해서 보일 때 재생 시작.
- **긴 영상·고품질 콘텐츠는 직접 호스팅하지 않기**: YouTube·Vimeo·Cloudflare Stream은 사용자 기기·네트워크에 맞춰 화질을 자동으로 낮추는 적응형 스트리밍을 해준다. 직접 호스팅보다 훨씬 안 느리다.

## 헷갈리기 쉬운 점
- `autoplay`는 `muted`가 같이 있어야 브라우저가 허용한다. 소리 있는 영상의 자동재생은 대부분 막힌다.
- 모바일에서 영상이 전체화면으로 튀는 걸 막으려면 `playsinline` 속성을 붙여야 한다.
- 버셀 같은 호스팅은 작은 코드·이미지 위주로 쓰기 좋게 되어 있다. 큰 영상 파일을 계속 올리면 저장공간·트래픽 비용이 불리해진다 → [[버셀]]

## 웹 개발에서는
- 배경 인트로 영상처럼 짧은 루프: `/public` 폴더에 압축된 mp4를 두고 `<video autoplay muted loop playsinline>`으로 직접 재생.
- 제대로 된 콘텐츠 영상(강의, 인터뷰 등): YouTube 미등록(unlisted) 업로드 후 `<iframe>` 임베드가 가장 간단하고 비용도 안 든다.
