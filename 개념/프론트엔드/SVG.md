# SVG

> 그림을 픽셀이 아니라 좌표와 선으로 적은 이미지 형식. 코드라서 HTML 안에 `<svg>` 태그로 바로 넣을 수 있다.

## 설명
- PNG·JPG는 점(픽셀)을 칸마다 저장한다. SVG는 "여기서 저기까지 선을 긋고 이 색으로 채워라"를 저장한다.
- 그래서 확대해도 깨지지 않고, 아이콘·로고처럼 단순한 그림은 파일도 작다.
- 웹에 넣는 방법은 두 가지다.

| 방법 | 코드 | 특징 |
|---|---|---|
| 파일로 넣기 | `<img src="logo.svg">` | 일반 이미지처럼 씀 |
| 코드로 넣기 (인라인) | `<svg><path d="M0 0 L10 10..."/></svg>` | 파일 요청이 없고 CSS로 색을 바꿀 수 있음 |

- `fill: currentColor`를 쓰면 SVG가 글자색(`color`)을 따라간다. 다크 모드에서 로고 색이 저절로 바뀌는 이유다.

## 비유
PNG는 모눈종이에 칸마다 색을 칠한 그림이고, SVG는 "이 점에서 저 점까지 선을 그어라"라고 적은 설명서다. 설명서는 종이를 키워도 다시 그리면 되니 깨지지 않는다.

## 헷갈리기 쉬운 점
- 화면에 그림이 보인다고 다 `<img>`가 아니다. 인라인 SVG, CSS `background-image`, `<canvas>`로도 그림이 나온다.
- 피그마에서 Export → SVG로 뽑은 파일이 이 형식이다. 열어 보면 글자(코드)다.
- 사진처럼 색이 복잡한 그림은 SVG가 오히려 커진다. 사진은 JPG·WebP가 맞다.

## 웹 개발에서는
- 개발자 도구 Elements에서 로고·아이콘을 찾으면 `<img>` 대신 `<svg>`와 `<path>`가 나오는 경우가 많다.
- Lucide 같은 아이콘 라이브러리도 아이콘을 인라인 SVG로 넣는다.
- AI에게 "아이콘은 SVG로, 색은 currentColor로"라고 하면 다크 모드 대응이 쉬워진다.
