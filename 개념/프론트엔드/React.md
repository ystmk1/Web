# React

> 화면을 [[컴포넌트]] 단위로 쪼개 만드는 JavaScript 라이브러리. Meta(옛 Facebook)가 만들었다.

## 설명
- 화면을 헤더, 카드, 버튼 같은 조각으로 나눠 만들고 조립한다.
- 조각은 [[JSX·TSX]]로 쓴다. HTML처럼 보이지만 JavaScript 파일이다.
- 데이터가 바뀌면 바뀐 부분만 화면에 다시 그린다.

## 비유
레고. 블록(컴포넌트)을 만들어 두고 조립해서 페이지를 만든다.

## 헷갈리기 쉬운 점
- React는 프레임워크가 아니라 **라이브러리**다. 화면 그리기만 맡는다.
- 주소별 페이지 나누기(라우팅), 서버 기능은 React에 없다. [[Next.js]] 같은 프레임워크가 더한다 → [[라우트]]
- 라이브러리·프레임워크의 근본적인 차이(누가 누구를 부르는지)는 → [[라이브러리 vs 프레임워크]]

## 웹 개발에서는
- "React로 해줘"와 "Next.js로 해줘"는 결과물이 다르다. 페이지가 여러 개면 보통 Next.js로 만든다.
- 실제 설치·사용 흐름: `npx create-next-app` 또는 `npm create vite -- --template react`로 프로젝트를 만들면 React가 자동 설치된다. 이후엔 `.jsx`/`.tsx` 파일에서 JSX를 쓰고, 필요한 기능만 `import`해서 쓴다 → [[Vite]]
