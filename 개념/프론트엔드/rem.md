# rem

> Root Em의 줄임말. 최상위 요소(`<html>`)의 글자 크기를 1로 삼는 [[CSS]] 길이 단위다.

## 설명
- 브라우저의 기본 글자 크기는 보통 16px다. 그래서 따로 설정을 바꾸지 않으면 `1rem = 16px`이다.
- `font-size`, `margin`, `padding`, `width` 등 거의 모든 크기 속성에 쓸 수 있다.

```css
html { font-size: 16px; }   /* 기본값, 보통 안 적어도 됨 */
h1 { font-size: 2rem; }     /* 32px */
p  { margin-bottom: 1rem; } /* 16px */
```

## 비유
건물 전체의 층고를 정하는 기준 하나. 모든 방의 가구 크기를 "층고의 몇 배"로 정해 두면, 층고 하나만 바꿔도 건물 전체 비례가 같이 바뀐다.

## 헷갈리기 쉬운 점
- **`rem` ≠ `em`.** `em`은 **부모 요소**의 글자 크기를 기준으로 삼는다. 요소가 중첩되면 부모의 배수가 또 자식의 기준이 되면서 크기가 겹겹이 쌓여(compounding) 예측하기 어려워진다. `rem`은 중첩 깊이와 상관없이 항상 최상위(html) 하나만 본다.
- **`rem` ≠ `px`.** `px`는 고정 픽셀이라 사용자의 브라우저 설정과 무관하다. `rem`은 사용자가 브라우저에서 기본 글자 크기를 키우면(저시력 사용자의 접근성 설정 등) 같이 커진다.

## 웹 개발에서는
- 글자 크기·여백처럼 전체적으로 비례를 맞추고 싶은 값에 `rem`을 많이 쓴다. 화면 크기에 따라 변하는 값은 [[뷰포트 단위]]를 쓴다.
- Tailwind CSS 같은 도구의 간격 클래스(`p-4`, `text-xl` 등)도 내부적으로 `rem` 값으로 되어 있다.
- 디자인 시안에서 픽셀(px)로 받은 값을 코드로 옮길 때, 16으로 나눠서 `rem` 값으로 바꾸는 작업을 자주 한다 (24px → 1.5rem).
