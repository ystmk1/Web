# CSS

> 웹 페이지의 색, 크기, 위치, 간격 같은 모양을 정하는 언어.

## 설명
- CSS는 Cascading Style Sheets의 줄임말이다. 번역하면 "겹쳐지는 스타일 시트"다.
- [[HTML]]이 페이지의 뼈대(제목, 문단, 버튼)를 만들면, CSS는 그 뼈대에 옷을 입힌다.
- CSS는 "선택자"로 대상을 고르고, 그 대상에 "속성: 값"을 적는다.

```css
h1 {
  color: blue;
  font-size: 32px;
}
```

위 코드는 모든 `h1` 제목을 파란색, 32픽셀 크기로 만든다.

## 비유
사람의 몸(HTML)에 옷과 화장을 입히는 일. 뼈대는 그대로 두고 겉모습만 바꾼다.

## 헷갈리기 쉬운 점
- CSS는 프로그래밍 언어가 아니다. 조건문이나 반복문이 없고, 모양만 정한다.
- "Cascading"은 여러 규칙이 겹칠 때 어느 규칙이 이길지 정하는 방식을 뜻한다. 같은 대상에 규칙이 여럿이면 더 구체적인 규칙이 이긴다.
- 같은 CSS라도 브라우저마다 결과가 조금씩 다를 수 있다 → [[크로스 브라우징]]

## 웹 개발에서는
- 파일은 보통 `.css` 확장자로 만들고, HTML에서 불러와 쓴다.
- 요즘은 Tailwind CSS 같은 도구로 클래스 이름만 붙여 쓰는 방식도 많이 쓴다. 이때도 결과는 결국 CSS다.
- 화면이 휴대폰과 PC에서 다르게 보이게 하려면 미디어 쿼리(`@media`)를 쓴다.
