# Tailwind CSS

> 미리 정해 둔 작은 클래스를 HTML에 붙여서 스타일을 입히는 CSS 도구. 클래스 하나가 CSS 규칙 하나다.

## 설명
- `px-6`, `bg-red-500`, `rounded-full`처럼 **한 가지 일만 하는 클래스**(유틸리티 클래스)를 미리 정해 두었다.
- 이름은 규칙을 따른다: `속성-값`. 예: `px-6` = 좌우 여백 6칸.
- 숫자는 정해 둔 단계(스케일)를 쓴다. 여백은 1칸 = 4px라서 `px-6` = 24px, `py-3` = 12px.
- 단계에 없는 값은 대괄호로 직접 적는다: `bg-[#FF3B29]`.
- 빌드할 때 Tailwind가 내 파일을 훑어서 **실제로 쓴 클래스만** CSS로 만들어 준다. 그래서 수천 개를 다 싣지 않는다.

## 비유
CSS 사전. 단어(클래스)와 뜻(CSS 규칙)이 미리 정해져 있고, 나는 단어를 골라 문장(HTML)에 붙이기만 한다.

## 헷갈리기 쉬운 점
- **완성된 버튼·카드 같은 부품을 주는 게 아니다.** 그건 shadcn/ui, daisyUI 같은 UI 부품 라이브러리다. Tailwind는 그 부품을 칠하는 붓에 가깝다.
- 결과물은 그냥 CSS다. 보통 CSS로 할 수 있는 것과 같은 결과가 나온다.
- 단계·색·폰트는 바꿀 수 있다. 브랜드 색을 등록하면 `bg-brand`처럼 쓸 수 있다 → [[디자인 토큰]]

## 웹 개발에서는
- AI가 만든 React·Next.js 코드에 `className="flex gap-4 p-6"`처럼 보이면 대부분 Tailwind다.
- 피그마 값과 거의 1:1로 대응해서 "padding 24, gap 16" 같은 말을 그대로 옮기기 쉽다.
