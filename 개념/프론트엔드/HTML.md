# HTML

> 웹 페이지의 뼈대를 적는 언어. 제목, 문단, 이미지, 버튼이 무엇인지 브라우저에게 알려준다.

## 설명
- HTML은 프로그래밍 언어가 아니라 **마크업 언어**다. 계산이나 판단을 하지 않고, 내용의 의미와 구조를 표시한다.
- 태그로 내용을 감싼다. 시작 태그 `<p>`와 끝 태그 `</p>` 사이의 글자가 문단이 된다.
- 브라우저는 HTML 파일을 위에서부터 읽어 [[렌더링 엔진]]이 화면을 만든다.

```html
<h1>내 첫 페이지</h1>
<p>안녕하세요.</p>
<img src="cat.jpg" alt="고양이 사진">
```

## 비유
집의 설계도 중 방 배치도. 어디에 거실이 있고 어디에 문이 있는지 정한다. 벽지 색이나 가구 배치는 다른 사람(CSS)이 맡는다.

## 헷갈리기 쉬운 점
- HTML ≠ 프로그래밍 언어. 반복문이나 조건문이 없다. 움직임은 [[JavaScript]]가 맡는다.
- 색과 크기는 HTML이 아니라 CSS가 정한다. `<p style="color: red">`처럼 쓸 수는 있지만, 보통은 스타일 파일을 따로 둔다.
- 태그를 닫지 않으면 화면이 깨질 수 있다. 시작과 끝 태그를 짝으로 맞춘다.

## 웹 개발에서는
- 화면의 구조가 HTML에 있으므로, 화면에 무엇이 보이지 않을 때 HTML부터 확인한다.
- 검색 엔진과 스크린 리더도 HTML 구조를 읽는다. 제목은 `<h1>`, 문단은 `<p>`처럼 의미에 맞는 태그를 쓴다.
- React나 Vue 같은 프레임워크도 결국 HTML을 만들어 브라우저에 보낸다.

## 관련 개념
- [[JavaScript]]: 화면을 움직이는 언어
- [[SVG]]: 선과 좌표로 그리는 이미지 형식. HTML 안에 넣을 수 있다.
- [[렌더링 엔진]]: HTML을 읽어 화면으로 바꾸는 부분
- [[크로스 브라우징]]: 브라우저마다 HTML을 다르게 보여주는 문제를 다룬다.
