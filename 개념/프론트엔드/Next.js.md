# Next.js

> [[React]]를 기반으로 실제 서비스를 만들기 좋게 기능을 더한 프레임워크.

## 설명
- React는 "화면을 어떻게 그릴지"만 담당하는 라이브러리다. 주소별 페이지 나누기, 서버 기능, 성능 최적화는 직접 다 짜야 한다.
- Next.js는 이런 걸 기본으로 갖추고 있다. 폴더 구조만 맞춰 만들면([[라우트]] 참고) 라우팅부터 서버 기능까지 알아서 돌아간다.

### 핵심 기능
- **파일 기반 라우팅**: `app/` 폴더 구조 = URL 구조 → [[라우트]]
- **서버 기능**: `app/api/` 같은 데서 백엔드 코드도 같은 프로젝트에서 작성
- **빌드·최적화**: 이미지 최적화, 미리 렌더링 등을 자동으로 해줌
- **[[버셀]]과 궁합**: Next.js를 만든 회사가 버셀이라, 깃허브 푸시 한 번으로 바로 배포된다

## 헷갈리기 쉬운 점
- "React로 화면을 그린다"와 "Next.js로 사이트를 만든다"는 결이 다르다. 페이지가 여러 개인 실제 사이트라면 보통 Next.js를 쓴다.
