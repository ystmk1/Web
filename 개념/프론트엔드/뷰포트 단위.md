# 뷰포트 단위

> 지금 보이는 화면(뷰포트)의 가로·세로 크기를 기준으로 삼는 [[CSS]] 길이 단위. `vw`(viewport width)와 `vh`(viewport height)가 기본이다.

## 설명
- `1vw` = 뷰포트 가로 폭의 1%, `1vh` = 뷰포트 세로 높이의 1%다.
- `100vw`, `100vh`를 쓰면 화면을 가로나 세로로 가득 채운다.

```css
.hero {
  width: 100vw;
  height: 100vh;
}
```

| 단위 | 기준 |
|---|---|
| `vw` | 뷰포트 가로 폭 |
| `vh` | 뷰포트 세로 높이 |
| `vmin` | 가로·세로 중 더 작은 쪽 |
| `vmax` | 가로·세로 중 더 큰 쪽 |

## 비유
화면이라는 종이를 100칸짜리 모눈종이로 나눈 것. 화면 크기가 바뀌면 칸 하나의 실제 크기도 같이 바뀌지만, "몇 칸짜리인지"는 그대로 유지된다.

## 헷갈리기 쉬운 점
- **모바일에서 `100vh`가 불안정하다.** 모바일 브라우저는 스크롤하면 주소창이 사라지면서 실제 보이는 화면 높이가 바뀐다. `100vh`는 이 변화를 안 따라가서, 화면을 꽉 채운 줄 알았는데 주소창에 가려지거나 빈 여백이 남는 문제가 흔하다.
- 이 문제를 고치려고 새 단위가 나왔다: `dvh`(동적, 실제 보이는 높이를 따라감), `svh`(주소창이 보일 때의 작은 높이), `lvh`(주소창이 사라졌을 때의 큰 높이). 요즘은 `100dvh`를 더 권장한다.
- `vw`/`vh`는 [[rem]]과 달리 사용자의 글자 크기 설정과는 관계없다. 오직 화면 크기에만 반응한다.

## 웹 개발에서는
- 전체 화면을 채우는 히어로 섹션, 모달 배경(오버레이) 같은 데 자주 쓴다.
- 반응형 글자 크기를 만들 때 `clamp(1rem, 2vw + 1rem, 3rem)`처럼 [[rem]]과 섞어 쓰기도 한다. 최소·최대 크기는 rem으로 고정하고, 중간 구간만 화면 크기에 비례하게 만드는 방식이다.
