# 라우트

> [[URL]]의 경로와 보여줄 페이지를 잇는 규칙. 이 연결 작업을 라우팅이라고 한다.

## 설명
Next.js에서는 폴더 구조가 곧 주소다.

```
app/
  page.jsx                → /
  about/page.jsx          → /about
  posts/[slug]/page.jsx   → /posts/아무거나
```

- `[slug]`처럼 대괄호 폴더는 **동적 라우트**다. 주소의 그 자리에 무엇이 오든 같은 파일이 받는다.
- 파일 하나가 틀이 되고, 들어온 [[slug]]로 글을 찾아 채운다. 글이 100개여도 파일은 하나다.

## 비유
아파트 우편함. 호수(주소)마다 칸이 정해져 있고, `[slug]`는 "어느 호수든 이 칸으로"라고 적어 둔 공용 칸이다.

## 헷갈리기 쉬운 점
- [[React]]만으로는 라우팅이 없다. Next.js 같은 프레임워크가 더한다.
- `[slug]`라는 이름은 관례다. `[id]`, `[name]`처럼 다른 이름도 된다.
- **DOM과는 무관하다.** [[DOM]]은 브라우저가 HTML을 읽어서 만드는 것이고, 라우팅은 서버 쪽에서 "이 폴더 구조대로 URL을 만들겠다"고 정하는 규칙이다. 완전히 다른 층의 일이다.
