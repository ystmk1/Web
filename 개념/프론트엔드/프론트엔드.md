# 프론트엔드

사용자 눈에 보이는 화면을 만드는 기술. 구조(HTML), 꾸미기(CSS), 움직임(JavaScript)과 그걸 편하게 만드는 프레임워크.

← [[Web Workshop 홈]]

## 개념
- [[HTML]]: 화면의 구조를 적는 언어
- [[CSS]]: 화면의 모양을 정하는 언어
  - [[rem]]: 최상위 글자 크기를 기준으로 삼는 단위
  - [[뷰포트 단위]]: 화면 크기를 기준으로 삼는 단위 (vw·vh)
  - [[Tailwind CSS]]: 미리 정해 둔 작은 클래스로 스타일을 입히는 도구
- [[JavaScript]]: 웹 화면을 움직이는 언어 (코드와 언어 카테고리)
  - [[JSX·TSX]]: JS 안에 HTML처럼 쓰는 문법, TSX는 TypeScript까지 더한 것
- [[React]]: 화면을 컴포넌트 단위로 만드는 라이브러리
  - [[라이브러리 vs 프레임워크]]: 누가 누구를 부르는지의 차이
  - [[컴포넌트]]: 재사용하는 화면 조각
  - [[Next.js]]: React 기반으로 서비스를 만들기 좋게 기능을 더한 프레임워크
    - [[라우트]]: 주소와 페이지를 잇는 규칙 (Next.js의 [slug])
    - [[프로젝트 폴더 구조]]: app·components·lib·hooks·types로 역할별 정리
- [[퍼블리셔]]: 시안을 HTML·CSS로 옮기는 직무
- [[크로스 브라우징]]: 어떤 OS·브라우저에서도 의도대로 보이게 만드는 일
- [[SVG]]: 좌표와 선으로 적은 이미지 형식 (로고·아이콘)
- [[영상 최적화]]: 웹에 영상을 넣을 때 느려지지 않게 하는 방법 (직접 호스팅 vs 임베드)
