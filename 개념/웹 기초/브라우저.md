# 브라우저

> 웹 주소로 [[웹 페이지|웹페이지]]를 받아와서 화면에 보여주고 실행하는 프로그램.

## 설명
- 하는 일: 주소로 요청 → HTML·CSS·[[JavaScript]] 파일을 받음 → [[렌더링 엔진]]이 화면을 그리고, JavaScript 엔진이 코드를 실행.
- 웹사이트 입장에서 브라우저는 [[운영체제]] 대신 기대는 공통 무대다. 그래서 같은 웹이 Windows에서도 Mac에서도 폰에서도 열린다.

| 브라우저 | 만든 곳 | 렌더링 엔진 |
|---|---|---|
| Chrome, Edge, 삼성 인터넷, Opera, Whale | Google 외 | Blink |
| Safari | Apple | WebKit |
| Firefox | Mozilla | Gecko |

- 아이폰·아이패드에서는 애플 규정 때문에 크롬·엣지를 깔아도 속은 Safari와 같은 WebKit이다.
- 개발자 도구(F12 또는 우클릭 → 검사): 페이지의 HTML·CSS를 들여다보고 바로 고쳐볼 수 있는 브라우저 내장 도구.

## 비유
악보(코드)를 받아 연주하는 연주자. 악보가 같아도 연주자마다 해석이 조금씩 다르다.

## 헷갈리기 쉬운 점
- 브라우저 ≠ 검색엔진. 크롬은 브라우저(프로그램), 구글·네이버는 검색 서비스(웹사이트)다.
- 브라우저 ≠ 인터넷. [[인터넷]]은 컴퓨터끼리 연결된 망이고, 브라우저는 그 위에서 웹을 보는 프로그램 중 하나.
- 개발자 도구의 모바일 화면 모드는 화면 크기만 흉내 낸다. 엔진은 그대로 크롬이라 아이폰 Safari와 똑같지 않다.

## 웹 개발에서는
- 내가 만든 웹의 실제 실행 환경은 방문자의 브라우저다. 그래서 브라우저마다 결과가 미세하게 다를 수 있다 → [[크로스 브라우징]]
- 개발 중에는 `localhost` 주소를 브라우저로 열어 결과를 확인한다.

## 관련 개념
