# IP 주소

> 인터넷에 연결된 기기마다 붙는 숫자 주소. 컴퓨터끼리는 이 번호로 상대를 찾는다.

## 설명
- 생김새: `203.0.113.10`처럼 0~255 숫자 네 개를 점으로 이은 형태(IPv4).
- 기기가 너무 많아져서 숫자가 모자라기 때문에, 더 긴 형태(IPv6, 예: `2001:db8::1`)도 같이 쓴다.
- 사람이 숫자를 외우기 어렵기 때문에 [[도메인]]이라는 이름을 붙이고, [[DNS]]가 이름을 IP 주소로 바꿔준다.

## 비유
건물의 지번 주소(숫자). 도메인은 "OO빌딩" 같은 이름이고, IP 주소는 실제 위치를 가리키는 번호다.

## 헷갈리기 쉬운 점
- 집 와이파이에 연결된 기기들은 공유기 안에서만 쓰는 내부 IP를 받는다. 바깥 인터넷에서는 공유기 하나의 IP로 보인다.
- `127.0.0.1`은 "내 컴퓨터 자신"을 뜻하는 특별한 주소다. `localhost`와 같다.

## 웹 개발에서는
- 도메인을 [[버셀|Vercel]]에 연결할 때 "A 레코드에 이 IP를 넣으세요" 같은 안내가 나온다. 내 도메인이 Vercel 서버의 IP를 가리키게 하는 설정이다 → [[DNS]]

## 관련 개념
- [[도메인]]: IP 주소에 붙인 사람용 이름
- [[DNS]]: 도메인을 IP 주소로 바꾸는 시스템
- [[인터넷]]: IP 주소로 서로를 찾는 망
