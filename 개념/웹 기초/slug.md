# slug

> [[URL]]에 쓰기 좋게 다듬은 문자열. 보통 소문자와 하이픈만 쓴다.

## 설명
- 글 제목처럼 띄어쓰기·특수문자가 섞인 텍스트를 주소에 그대로 쓰면 읽기도 어렵고 문제가 생길 수 있다.
- slug는 이를 깔끔하게 다듬은 버전이다. 예: "오늘의 날씨" → `today-weather` 또는 `오늘의-날씨`.
- 보통 공백은 하이픈(`-`)으로 바꾸고, 특수문자는 없앤다.

## 웹 개발에서는
- 블로그 글, 상품 페이지처럼 하나하나 [[URL]]이 필요한 콘텐츠에서 `/posts/my-first-post` 같은 형태로 흔히 쓴다.
- 사람이 읽기 쉽고, 검색엔진에도 더 잘 노출된다.

## 관련 개념
- [[URL]]: slug가 들어가는 자리
