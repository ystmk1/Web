# DNS

> 도메인 이름을 실제 서버의 IP 주소로 바꿔주는 시스템. Domain Name System.

## 설명
- 인터넷의 모든 [[서버]]는 IP 주소(예: `142.250.206.46`)라는 숫자로 식별된다.
- 사람은 숫자 주소를 외우기 어려워서, `google.com` 같은 이름을 쓴다.
- DNS는 이 이름과 실제 IP 주소를 연결해주는 전화번호부 역할을 한다.
- 브라우저에 주소를 입력하면, 먼저 DNS에 "이 이름의 IP 주소가 뭐야?"라고 물어보고, 받은 IP로 실제 접속한다.

## 비유
전화번호부. 사람 이름(도메인)으로 찾으면, 번호부가 실제 전화번호(IP 주소)를 알려주고, 그 번호로 전화를 건다.

## 웹 개발에서는
- 직접 산 도메인을 [[버셀]] 같은 호스팅에 연결할 때, 도메인 관리 사이트에서 "DNS 설정"을 바꿔서 그 도메인이 호스팅의 서버를 가리키도록 만든다.
- Cloudflare는 원래 DNS·CDN을 다루던 회사다.
