# DNS

> 사람이 읽는 주소(도메인)를 컴퓨터 주소(IP 주소)로 바꿔주는 인터넷의 전화번호부. Domain Name System의 줄임말이다.

## 설명
주소창에 `naver.com`을 치면 이런 일이 먼저 일어난다.

```
1. 브라우저: "naver.com의 IP가 뭐지?" (최근에 물어본 적 있으면 저장해둔 답을 씀)
2. 인터넷 회사의 DNS 서버에 물어봄
3. 모르면 단계별로 물어 내려감: .com 담당 → naver.com 담당
4. "223.xxx.xxx.xxx야" 답을 받음
5. 그제야 그 IP로 진짜 요청을 보냄
```

- 한 번 받은 답은 한동안 저장(캐시)해두기 때문에, 다음부터는 빨리 찾는다.

### DNS 레코드: 전화번호부의 한 줄
| 종류 | 뜻 |
|---|---|
| A 레코드 | 도메인 → IP 주소 |
| CNAME 레코드 | 도메인 → 다른 도메인 ("저쪽 주소를 따라가") |
| MX 레코드 | 이 도메인의 메일은 어느 서버로 |

## 비유
전화번호부. 이름(도메인)을 찾으면 번호(IP 주소)가 나온다. 사람은 이름만 기억하면 된다.

## 헷갈리기 쉬운 점
- DNS 설정을 바꿔도 바로 반영되지 않는다. 곳곳에 저장된 옛 답이 지워져야 하기 때문에 몇 분에서 길게는 하루 이상 걸릴 수 있다.
- DNS는 주소를 찾아줄 뿐이다. 사이트 내용을 보내주는 건 [[서버]]다.

## 웹 개발에서는
- 내 도메인을 [[버셀|Vercel]]에 연결할 때, 도메인 등록 업체의 DNS 설정에 Vercel이 알려주는 A 레코드나 CNAME 레코드를 넣는다.
- 연결이 안 되면 대부분 레코드 값 오타이거나, 아직 반영 중인 경우다.
