# URL

> 인터넷에 있는 페이지나 파일 하나하나의 주소. Uniform Resource Locator의 줄임말이다.

## 설명
```
https://www.example.com:443/blog/post-1?sort=new#comments
└─┬─┘   └──────┬──────┘└┬┘└────┬────┘└───┬───┘└───┬───┘
프로토콜    도메인     포트    경로     쿼리      위치
```

| 부분 | 뜻 |
|---|---|
| 프로토콜 | 어떤 규칙으로 주고받을지 ([[HTTP]], HTTPS) |
| 도메인 | 어느 서버로 갈지 → [[도메인]] |
| 포트 | 서버의 몇 번 문으로 들어갈지. 보통 생략한다 → [[포트]] |
| 경로 | 서버 안의 어느 페이지·파일인지 |
| 쿼리 | 추가 조건 (`?` 뒤, 검색어·정렬 등) |
| 위치 | 페이지 안의 특정 위치 (`#` 뒤) |

## 비유
택배 주소. 도메인은 건물 이름, 경로는 동·호수, 쿼리는 "부재 시 문 앞에" 같은 메모다.

## 헷갈리기 쉬운 점
- URL에는 항상 슬래시(`/`)를 쓴다. Windows 폴더 경로(`\`)와 다르다.
- 이미지 하나, CSS 파일 하나에도 각자 URL이 있다. 웹 페이지만 주소를 갖는 게 아니다.

## 웹 개발에서는
- Next.js에서는 폴더 구조가 곧 URL의 경로가 된다 → [[라우트]]
- `/blog/post-1`의 `post-1`처럼 사람이 읽기 좋게 만든 주소 조각을 [[slug]]라고 한다.

## 관련 개념
- [[도메인]]: URL 안의 서버 이름
- [[HTTP]]: URL 맨 앞의 프로토콜
- [[웹 페이지]]: URL 하나로 열리는 문서
- [[포트]]: URL 안의 문 번호
