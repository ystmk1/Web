# 서버

> 요청을 기다렸다가 응답해주는 쪽. 웹 페이지, 데이터, 파일을 갖고 있다가 달라는 클라이언트에게 보내준다.

## 설명
- 서버도 기계 이름이 아니라 **역할** 이름이다. 특별한 기계가 아니라, 서버 프로그램이 켜져 있는 평범한 컴퓨터다.
- 서버 프로그램은 정해진 [[포트]]를 열어두고 요청이 오기를 계속 기다린다. 그래서 서버 컴퓨터는 24시간 켜져 있어야 한다.
- 실제 서비스의 서버는 대부분 [[리눅스]] 컴퓨터이고, 데이터센터에 모여 있다.

| 하는 일 | 예 |
|---|---|
| 웹 페이지 보내기 | HTML·CSS·JS·이미지 파일 |
| 데이터 처리 | 로그인 확인, 결제, 게시물 저장 |
| 파일 보관 | 카톡으로 보낸 사진을 잠시 보관 |
| 데이터베이스 연결 | 회원 정보, 게시물 목록 꺼내기 |

## 비유
식당의 주방. 손님(클라이언트)이 주문하면 요리(응답)를 만들어 내보낸다. 손님이 언제 올지 모르기 때문에 영업시간 내내 불을 켜두고 기다린다.

## 헷갈리기 쉬운 점
- 서버 ≠ 큰 기계. 내 노트북도 `npm run dev`를 하면 서버 역할을 한다.
- 서버를 직접 사서 둘 필요는 없다. 남의 서버를 빌려 쓰는 게 [[웹 호스팅]]이다.

## 웹 개발에서는
- 백엔드 개발은 서버에서 돌아가는 코드를 만드는 일이다.
- Vercel에 배포하면 Vercel의 서버가 내 사이트를 대신 응답해준다.
- 서버에서 에러가 나면 응답 코드 500번대가 온다 → [[HTTP 상태 코드]]
