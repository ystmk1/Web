# 렌더링 엔진

> 브라우저 안에서 HTML·CSS를 읽어 실제 화면(픽셀)으로 그려내는 부분. 브라우저 엔진이라고도 한다.

## 설명
- 렌더링 = 코드를 눈에 보이는 화면으로 바꾸는 것. HTML로 구조를 파악하고, CSS로 위치·크기·색을 계산해서 그린다.
- 지금 쓰이는 엔진은 사실상 세 가지다.
  - **Blink**: Chrome, Edge, 삼성 인터넷 등 대부분
  - **WebKit**: Safari, 그리고 아이폰의 모든 브라우저
  - **Gecko**: Firefox
- 웹 표준(HTML·CSS 규칙)은 하나지만, 그걸 구현하는 엔진이 다르다. 새 CSS 기능을 지원하기 시작하는 시점이나 세부 계산이 조금씩 다를 수 있다.

## 비유
같은 악보를 연주하는 서로 다른 오케스트라. 곡은 같은데 해석과 음색이 미묘하게 다르다.

## 헷갈리기 쉬운 점
- 브라우저 이름이 달라도 엔진은 같을 수 있다. 크롬과 엣지는 엔진이 같아서 결과가 거의 같다.
- 아이폰에서는 크롬도 WebKit을 쓰기 때문에, "아이폰에서만 깨져요"는 대부분 WebKit 차이다.

## 웹 개발에서는
- 새로 나온 CSS 기능을 쓸 때는 caniuse.com에서 엔진별 지원 여부를 확인하는 습관이 좋다.
- 최소한 크롬(Blink)과 아이폰 Safari(WebKit) 두 곳에서는 직접 열어보고 확인한다.
