# 클라이언트

> 서비스를 받으려고 요청을 보내는 쪽. 웹에서는 보통 사용자의 브라우저나 앱이다.

## 설명
- 클라이언트는 기계 이름이 아니라 **역할** 이름이다. 요청하는 쪽이 클라이언트다.
- 예: 크롬(웹사이트를 요청), 카카오톡 앱(메시지·사진을 요청), 인스타그램 앱(피드를 요청).
- 클라이언트는 사용자 눈앞에서 돌아간다. 그래서 화면을 그리고, 사용자 입력을 받는다.

## 비유
식당의 손님. 메뉴를 보고 주문(요청)하고, 나온 음식(응답)을 받는다.

## 헷갈리기 쉬운 점
- 같은 컴퓨터가 클라이언트도 되고 서버도 된다. 내 노트북의 브라우저는 클라이언트이고, 같은 노트북에서 `npm run dev`로 켠 [[개발 서버]]는 서버다.
- 서버도 다른 서버에 요청하면 그 순간에는 클라이언트다.

## 웹 개발에서는
- 프론트엔드 코드는 클라이언트(방문자 브라우저)에서 돌아간다. 그래서 누구나 코드를 볼 수 있고, 비밀 값을 넣으면 안 된다 → [[환경 변수]]
- Next.js 코드에서 `"use client"`라는 줄은 "이 부분은 클라이언트(브라우저)에서 돌려라"라는 뜻이다.
