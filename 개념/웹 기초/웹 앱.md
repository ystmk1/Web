# 웹 앱

> 프로그램처럼 동작하는 웹 페이지. 그중 홈 화면에 설치해서 앱처럼 쓰게 만든 것을 PWA(Progressive Web App)라고 부른다.

## 설명
- 웹 앱도 [[웹 페이지]]와 원리가 같다. HTML·CSS·[[JavaScript]]로 만들고 [[브라우저]]가 실행한다.
- 읽기만 하는 페이지가 아니라 누르고 저장하고 편집하는 일을 한다. 피그마, 구글 문서, 노션 웹이 웹 앱이다.
- PWA는 웹 앱에 두 가지를 더한 것이다.
  - manifest 파일: 앱 이름, 아이콘, 시작 화면을 적은 설명서
  - service worker: 오프라인 저장과 푸시 알림을 맡는 뒤편 스크립트

| | 그냥 웹 | PWA | [[네이티브 앱]] |
|---|---|---|---|
| 여는 법 | 주소 입력 | 홈 화면 아이콘 | 홈 화면 아이콘 |
| 설치 | 없음 | 홈 화면에 추가 | 스토어에서 설치 |
| 주소창 | 있음 | 없음 | 없음 |
| 푸시 알림 | 안 됨 | 됨 (iOS는 16.4부터) | 됨 |
| 업데이트 | 새로고침 | 새로고침 | 다시 받기 · 스토어 심사 |
| 기기 기능 | 일부 | 일부 | 깊게 (블루투스·NFC 등) |

- iOS 26부터는 Safari에서 홈 화면에 추가한 사이트가 기본으로 웹 앱으로 열린다. 사이트가 PWA 설정을 안 했어도 그렇다.

## 비유
매장(앱 스토어)에 입점하지 않고 내 가게 문 앞에 간판만 단 팝업 스토어. 들어오기는 쉽지만, 매장 안 설비(기기 기능)는 다 쓰지 못한다.

## 헷갈리기 쉬운 점
- 웹 앱 ≠ 앱 스토어 앱. 홈 화면에 아이콘이 있어도 속은 브라우저 엔진이 돌린다.
- 폰 앱 중에도 속은 웹인 것이 많다. 앱 껍데기 안에 웹 화면(WebView)을 띄우는 방식이다. 토스 안의 미니앱도 이 방식으로 만들 수 있다.
- "웹 앱"과 "웹사이트"의 경계는 정해져 있지 않다. 기능이 많아질수록 웹 앱이라고 부를 뿐이다.

## 웹 개발에서는
- AI에게 "PWA로 만들어줘"라고 하면 manifest 파일과 아이콘을 만들어 붙여 준다.
- 처음에는 웹으로 만들고, 폰에서 앱처럼 쓰고 싶으면 PWA를 더하고, 스토어가 꼭 필요할 때 앱을 만드는 순서가 부담이 적다.
