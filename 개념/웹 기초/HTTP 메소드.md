# HTTP 메소드

> 요청을 보낼 때 "무엇을 하고 싶은지"를 나타내는 단어. 같은 주소라도 메소드에 따라 서버가 하는 일이 달라진다.

## 설명
| 메소드 | 뜻 | 인스타그램으로 치면 |
|---|---|---|
| **GET** | 가져오기 | 피드 보기, 사진 열기 |
| **POST** | 새로 보내기·만들기 | 게시물 올리기, 댓글 달기 |
| **PATCH** | 일부 수정 | 캡션만 고치기 |
| **PUT** | 통째로 바꾸기 | 프로필 정보 전체 다시 저장 |
| **DELETE** | 삭제 | 게시물 지우기 |

- 이 네다섯 개로 대부분의 일을 표현한다. 데이터를 만들고(Create), 읽고(Read), 고치고(Update), 지우는(Delete) 일을 묶어서 **CRUD**라고 한다.

## 비유
은행 창구의 용건. 같은 창구(주소)에 가도 "조회요", "입금이요", "정보 변경이요", "해지요"에 따라 직원이 하는 일이 다르다.

## 헷갈리기 쉬운 점
- 주소창에 주소를 치고 들어가는 건 항상 GET이다.
- 로그인 버튼을 누르면 보통 POST다. 비밀번호가 주소창에 드러나지 않게 요청 본문에 담아 보낸다.
- 메소드는 약속일 뿐이다. GET으로 삭제하게 만들 수도 있지만, 그러면 헷갈리고 위험하기 때문에 규칙대로 쓴다.

## 웹 개발에서는
- 바이브코딩 중 AI가 "GET 요청으로 목록을 불러오고, POST로 저장한다" 같은 말을 쓰면 이 뜻이다.
- Next.js에서 서버 기능(API)을 만들 때 `GET`, `POST` 이름의 함수를 만들어서 메소드별로 할 일을 나눈다.
