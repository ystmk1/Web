# 웹 기초

웹이 어떻게 동작하는지에 대한 개념. 주소창에 주소를 치면 무슨 일이 일어나는지, 컴퓨터끼리 어떻게 주고받는지.

← [[Web Workshop 홈]]

## 개념
읽는 순서대로.
- [[인터넷]]: 전 세계 컴퓨터를 이은 통신망
- [[웹]]: 인터넷 위에서 문서를 링크로 이어 보는 공간 (WWW)
- [[웹 페이지]]: 주소 하나로 열리는 웹 문서 한 장
  - [[웹 앱]]: 프로그램처럼 동작하는 웹 페이지 (PWA 포함)
- [[클라이언트]] · [[서버]]: 요청하는 쪽과 응답하는 쪽
- [[요청과 응답]]: 웹 통신의 기본 단위
  - [[HTTP]]: 요청과 응답의 규칙
  - [[HTTP 메소드]]: GET·POST·PATCH·DELETE
  - [[HTTP 상태 코드]]: 200·404·500
- [[URL]]: 페이지·파일의 주소
- [[IP 주소]] · [[도메인]] · [[DNS]]: 숫자 주소, 이름 주소, 둘을 잇는 전화번호부
- [[브라우저]]: 웹페이지를 받아와 보여주고 실행하는 프로그램
  - [[렌더링 엔진]]: 브라우저 안에서 화면을 그리는 부분 (Blink, WebKit, Gecko)
  - [[DOM]]: 브라우저가 HTML을 읽어 만드는 트리 모양 객체
- [[포트]]: 한 컴퓨터 안에서 프로그램마다 받는 통신 번호표
