# 웹

> 인터넷 위에서 문서끼리 링크로 이어 보는 정보 공간. 정식 이름은 World Wide Web(WWW)이다.

## 설명
- 1989년에 CERN(유럽 입자물리연구소)의 연구원 **팀 버너스리**가 제안했다. 연구자들이 서로 다른 컴퓨터에 흩어진 자료를 쉽게 공유하게 하려는 목적이었다.
- 1990년에 첫 웹 서버와 첫 브라우저를 만들었고, 1991년에 일반에 공개했다. 1993년에 CERN이 웹 기술을 누구나 무료로 쓸 수 있게 풀면서 빠르게 퍼졌다.
- 팀 버너스리는 1994년에 웹 표준을 정하는 단체 W3C를 세웠다.

### 웹을 이루는 세 가지 발명
| 기술 | 역할 | 도서관 비유 |
|---|---|---|
| HTML | 문서를 쓰는 형식. 다른 문서로 가는 링크를 넣을 수 있다 | 책의 내용 |
| [[URL]] | 문서마다 붙는 주소 | 청구기호 |
| [[HTTP]] | 문서를 요청하고 받는 약속 | 대출 규칙 |

문서들이 링크로 거미줄처럼 이어져 있기 때문에 이름이 World Wide Web(전 세계에 퍼진 거미줄)이다.

### 주소의 www.
- `www.naver.com`의 `www`는 "이 컴퓨터가 웹 서버다"라는 표시로 붙이던 이름(서브도메인)이다.
- 옛날에는 한 회사가 메일 서버(`mail.`), 파일 서버(`ftp.`), 웹 서버(`www.`)를 따로 두고 이름으로 구분했다.
- 지금은 필수가 아니다. `naver.com`처럼 www 없이도 대부분 같은 사이트로 연결된다 → [[도메인]]

## 비유
[[인터넷]]이 전 세계에 깔린 도로망이라면, 웹은 그 도로 위를 다니는 서비스 중 하나다. 이메일, 메신저, 게임도 같은 도로를 쓴다.

## 헷갈리기 쉬운 점
- 인터넷 ≠ 웹. 인터넷은 컴퓨터끼리 연결된 망이고, 웹은 그 위에서 돌아가는 서비스 중 하나다. 인터넷이 먼저 생겼고 웹은 1989년에 나왔다.
- 웹 ≠ 브라우저. [[브라우저]]는 웹을 보는 프로그램이다.
- 앱도 인터넷을 쓰지만 웹은 아닐 수 있다. 카카오톡 메시지는 인터넷으로 오가지만, 웹페이지를 보는 건 아니다.

## 웹 개발에서는
- 웹 개발은 HTML·CSS·JavaScript로 [[웹 페이지]]를 만들고, URL로 주소를 붙이고, HTTP로 주고받게 하는 일이다. 30년 넘게 이 바탕 구조는 그대로다.
- [[버셀|Vercel]]에 도메인을 연결할 때 `www`가 있는 주소와 없는 주소를 둘 다 등록하고, 한쪽으로 자동 이동(리디렉트)하게 하는 경우가 많다.
