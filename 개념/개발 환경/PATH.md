# PATH

> 터미널에 명령어를 쳤을 때, 운영체제가 그 프로그램을 찾으러 가는 폴더 목록. OS가 들고 있는 주소록.

## 설명
- [[터미널]]에 `node`라고 치면, OS는 "node라는 프로그램이 어디 있지?" 하고 PATH에 적힌 폴더들을 차례로 뒤진다. 찾으면 실행하고, 못 찾으면 "명령어를 찾을 수 없습니다"를 띄운다.
- PATH도 [[환경 변수]]의 하나다. 프로그램을 설치하면 설치 프로그램이 보통 자기 폴더를 PATH에 추가해준다.

## 비유
전화번호부. 이름(명령어)만 말하면 번호부(PATH)를 뒤져서 연결해준다. 번호부에 없으면 아무리 이름을 불러도 연결이 안 된다.

## 헷갈리기 쉬운 점
- 설치는 됐는데 명령어가 안 되는 경우가 많다. 프로그램은 있는데 주소록에 등록이 안 됐거나, **등록 전에 열어둔 터미널**이라 옛날 주소록을 보고 있는 것이다.
- 그래서 설치 후 **터미널을 새로 열면** 해결되는 경우가 많다. VS Code 안의 터미널이면 VS Code를 껐다 켠다.

## 웹 개발에서는
- Node.js를 설치한 직후 `node -v`, `npm -v`가 안 되면 대부분 이 문제다.
- 워크숍 세팅 실습에서 거의 확실히 마주치는 에러 중 하나.
