# node_modules

> npm으로 설치한 패키지(React 등)가 실제로 저장되는 폴더. 프로젝트마다 따로 생긴다.

## 설명
설치 범위는 두 층으로 나뉜다.

| | 설치 범위 | 예 |
|---|---|---|
| [[Node.js]], npm | 컴퓨터에 한 번만 설치 (전역) | 이게 있어야 `npm` 명령 자체를 쓸 수 있음 |
| [[React]] 같은 패키지 | 프로젝트마다 각각 설치 | 각 프로젝트의 `node_modules/` 폴더 안에 따로 들어감 |

```
project-a/
  node_modules/react/   ← A만의 React
  package.json

project-b/
  node_modules/react/   ← B만의 React (버전이 달라도 됨)
  package.json
```

- `package.json`: 이 프로젝트에 어떤 패키지가 필요한지 적어두는 목록(명단).
- `node_modules/`: 그 목록을 보고 실제로 내려받은 패키지 실물이 쌓이는 폴더.
- `npm install`을 실행하면 `package.json`을 읽어서 `node_modules`를 채운다.

## 헷갈리기 쉬운 점
- Node.js를 설치했다고 React가 저절로 쓸 수 있게 되는 게 아니다. React는 프로젝트별로 따로 설치해야 한다.
- `node_modules`는 용량이 크고 언제든 다시 만들 수 있어서 [[깃이그노어]]에 넣고 커밋하지 않는다. 대신 `package.json`만 공유하면, 받은 사람이 `npm install`로 똑같이 복원할 수 있다.

## 웹 개발에서는
- 프로젝트마다 React 버전이 달라도 된다. 전역으로 하나만 깔려 있으면 둘 다 만족시킬 수 없기 때문에, 프로젝트별 설치가 "내 컴퓨터엔 되는데 남 컴퓨터엔 안 돼요" 문제를 막아준다.
- 새 프로젝트를 만들 때마다(`npm install` 또는 `create-next-app` 실행 시 자동으로) 패키지가 그 프로젝트 폴더 안에 다시 설치된다.
