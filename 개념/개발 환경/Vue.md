# Vue

> 화면을 만드는 데 쓰는 JavaScript 라이브러리. React와 같은 역할을 하는 다른 선택지.

## 설명
- 버튼, 목록, 입력창 같은 화면 조각을 컴포넌트라는 단위로 만들어 조립한다.
- 데이터가 바뀌면 화면도 알아서 바뀐다. 사용자가 화면을 직접 고치는 코드를 쓰지 않아도 된다.
- 한 컴포넌트 파일에 화면 모양, 동작, 스타일을 함께 적는 방식이 대표적이다. 파일 확장자는 `.vue`다.
- Vue는 Vite를 만든 사람이 함께 만든 라이브러리다. 그래서 [[Vite]]와 짝지어 쓰는 일이 많다.

## 비유
레고 블록 세트. 작은 블록(컴포넌트)을 만들어 두고, 필요할 때 끼워 맞춰 큰 모형(화면)을 완성한다. React도 같은 레고지만, 블록의 모양과 끼우는 방법이 조금 다르다.

## 헷갈리기 쉬운 점
- Vue는 빌드 도구가 아니다. 화면을 어떻게 만들지 정하는 쪽이다. 코드를 묶고 실행해 주는 일은 [[Vite]]가 맡는다.
- Vue는 React와 경쟁하는 관계다. 보통 한 프로젝트에서 둘 중 하나만 고른다.
- Vue만 쓰면 라이브러리에 가깝다. 구조와 규칙까지 정해 주는 Nuxt 같은 프레임워크를 얹어 쓰기도 한다.

## 웹 개발에서는
- 새 프로젝트를 만들 때 Vite가 "React로 할까요, Vue로 할까요?" 하고 묻는다. 이때 고르는 선택지 중 하나다.
- 바이브코딩 중 AI가 "Vue로 만들겠습니다"라고 하면 이 이야기다. 이 경우 파일이 `.vue`로 끝난다.
- 워크숍에서는 React 쪽을 주로 쓴다. Vue는 이름과 역할만 알아 두면 된다.
