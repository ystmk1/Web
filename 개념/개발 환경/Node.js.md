# Node.js

> [[JavaScript]]를 [[브라우저]] 밖에서도 실행하게 해주는 프로그램이다. 내 컴퓨터나 [[서버]]에서 JavaScript 코드를 돌릴 수 있게 해준다.

## 설명
- 원래 JavaScript는 브라우저 안에서만 실행됐다. 브라우저 안에 JavaScript를 읽고 실행하는 엔진이 들어 있기 때문이다.
- Node.js는 크롬의 JavaScript 엔진(V8)을 브라우저 밖으로 꺼내서 따로 실행할 수 있게 만든 [[프로그램]]이다.
- 그래서 Node.js를 설치하면 터미널에서 `node 파일이름.js`로 JavaScript 파일을 바로 실행할 수 있다.
- Node.js를 설치하면 npm이라는 패키지 관리 도구도 함께 설치된다. npm은 남이 만든 코드 묶음(패키지)을 내려받는 도구다.
- 이런 프로그램을 **실행 환경**(런타임, Runtime)이라고 부른다.

| | 브라우저 안의 JavaScript | Node.js 안의 JavaScript |
|---|---|---|
| 어디서 도나 | 방문자의 브라우저 | 내 컴퓨터, 서버 |
| 할 수 있는 일 | 화면 바꾸기, 버튼 반응 | 파일 읽고 쓰기, 서버 열기 |
| 못 하는 일 | 내 컴퓨터 파일 마음대로 읽기 | 화면(웹 페이지)을 직접 그리기 |
| 실행 방법 | 웹 페이지를 열면 자동 실행 | 터미널에서 명령어로 실행 |

## 비유
레시피(JavaScript 코드)와 주방(실행 환경)의 관계다. 예전에는 이 레시피를 식당(브라우저) 주방에서만 만들 수 있었다. Node.js는 같은 레시피를 집에서도 만들 수 있게 해주는 가정용 주방이다. 레시피는 같지만 주방에 있는 도구는 조금 다르다.

## 헷갈리기 쉬운 점
- **Node.js는 언어가 아니다.** 언어는 JavaScript이고, Node.js는 그 언어를 실행하는 프로그램이다.
- **Node.js와 npm은 다르다.** Node.js는 코드를 실행하고, npm은 패키지를 설치하고 관리한다. 같이 설치되기 때문에 헷갈리기 쉽다.
- **브라우저 기능은 Node.js에 없다.** `document`, `window`처럼 화면과 관련된 기능은 브라우저에만 있기 때문에 Node.js에서 쓰면 에러가 난다.
- **설치했는데 `node` 명령어가 안 먹힐 수 있다.** 이때는 [[운영체제]]가 node 프로그램의 위치를 모르는 경우가 많다 → [[PATH]]

## 웹 개발에서는
- `npm run dev`를 하면 Node.js가 [[개발 서버]]를 켠다. 그래서 브라우저에서 `localhost:3000`처럼 [[localhost]]와 [[포트]] 번호로 내 사이트를 볼 수 있다.
- React, Next.js, Vite 같은 프론트엔드 도구도 개발할 때는 Node.js 위에서 돌아간다. 그래서 프론트엔드만 만들어도 Node.js를 설치해야 하는 경우가 많다.
- 백엔드 서버를 JavaScript로 만들 때도 Node.js를 쓴다. 이 경우 프론트엔드와 백엔드를 같은 언어로 만들 수 있다.
- Node.js 코드는 `process.env`로 [[환경 변수]]를 읽는다. API 키 같은 비밀 값은 이렇게 코드 바깥에서 건넨다.
- 프로젝트마다 필요한 Node.js 버전이 다를 수 있다. 에러가 나면 `node -v`로 버전부터 확인하면 좋다.
