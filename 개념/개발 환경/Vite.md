# Vite

> 코드를 빠르게 [[빌드]]하고, 개발할 때 변경사항을 즉시 보여주는 [[개발 서버]] 역할을 하는 빌드 도구.

## 설명
- Vite는 [[라이브러리 vs 프레임워크]]의 "제어의 역전" 같은 규칙이 없다. 화면을 어떻게 구성할지엔 관여하지 않는다.
- React를 쓰든 Vue를 쓰든, Vite는 그 코드를 빠르게 묶고 실행해 주는 도구일 뿐이다. 그래서 보통 "Vite + React", "Vite + Vue"처럼 라이브러리와 짝지어 쓴다.

| 분류 | 역할 | 예 |
|---|---|---|
| 빌드 도구 | 코드를 묶고 실행 준비 | Vite, Webpack |
| 라이브러리 | 화면을 어떻게 만들지 (내가 호출) | React |
| 프레임워크 | 코드 구조·규칙까지 정함 (저쪽이 호출) | Next.js |

## 헷갈리기 쉬운 점
- Vite는 프레임워크가 아니다. 빌드 도구다.
- [[Next.js]]는 내부적으로 이미 자체 빌드 시스템(Turbopack/Webpack)을 포함하고 있어서, Next.js를 쓸 땐 Vite를 따로 안 쓴다.
- Vite는 보통 "프레임워크 없이 React만 가볍게 쓰고 싶을 때" 선택한다.
