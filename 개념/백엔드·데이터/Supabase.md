# Supabase

> 오픈소스 [[BaaS]]. 로그인·데이터베이스·파일 저장을 직접 만들지 않고 바로 쓸 수 있게 해준다. "오픈소스 Firebase"로도 불린다.

## 설명
원래 직접 짜야 했던 백엔드 일을 세 가지로 묶어서 대신 제공한다.

| 원래 직접 해야 하는 일 | Supabase가 대신 해주는 것 |
|---|---|
| 회원가입·로그인, 비밀번호 암호화 | Auth 기능 — 몇 줄 코드로 로그인 완성 |
| [[데이터베이스]] 설치·운영 | PostgreSQL이 이미 세팅되어 있음 |
| "이 글은 작성자만 수정 가능" 권한 체크 | Row Level Security — 규칙을 설정만 하면 됨 |

- 프론트엔드에서 Supabase가 주는 라이브러리 함수만 호출하면 된다. 예: `supabase.from("posts").insert(...)`.
- [[데이터베이스]]로 PostgreSQL(관계형, SQL)을 쓴다. Firebase는 NoSQL을 쓴다는 점이 가장 큰 차이다.

## 비유
완제품 가전이 아니라, 전기·배관·보안까지 이미 다 된 세입자용 오피스텔. 내 물건(프론트엔드 화면)만 들여놓으면 바로 산다.

## 웹 개발에서는
- 워크숍처럼 짧은 시간에 "진짜 작동하는" 프로젝트(로그인 되고, 데이터 저장되는)를 만들 때, 백엔드를 처음부터 짜는 대신 Supabase를 붙이는 게 훨씬 현실적이다.
- 프론트엔드(HTML·CSS·JS, [[버셀]]로 배포)는 "보여주는 쪽", Supabase는 "원래 직접 서버·DB를 만들어야 했던 일을 대신 해주는 쪽"으로 역할이 나뉜다.
