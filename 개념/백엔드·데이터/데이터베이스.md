# 데이터베이스

> 데이터를 구조적으로 저장하고, 찾고, 바꾸고, 지울 수 있게 관리하는 프로그램. [[CRUD]] 작업의 대상.

## 설명
- 새로고침해도, 서버를 껐다 켜도 데이터가 사라지지 않고 남아있게 해주는 저장소다.
- 크게 두 종류로 나뉜다.
  - **관계형(SQL)**: 표(테이블) 형태로 저장. 예: PostgreSQL, MySQL. [[Supabase]]가 이 방식을 쓴다.
  - **비관계형(NoSQL)**: 문서·키값 형태로 저장. 예: MongoDB, Firestore(Firebase).
- [[서버]]가 데이터베이스에 접속해서 데이터를 읽고 쓴다. 브라우저가 데이터베이스에 직접 접속하지 않는다.

## 웹 개발에서는
- 직접 설치·운영하려면 서버에 데이터베이스 프로그램을 깔고, 백업·보안까지 신경 써야 한다.
- [[BaaS]]를 쓰면 이미 세팅된 데이터베이스를 바로 쓸 수 있다.

## 관련 개념

- [[서버]]: 데이터베이스에 접속하는 쪽
- [[Supabase]]: PostgreSQL 데이터베이스를 기본 제공하는 BaaS
