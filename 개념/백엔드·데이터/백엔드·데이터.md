# 백엔드·데이터

화면 뒤에서 돌아가는 쪽. 요청을 받아 처리하는 서버, 서로 주고받는 약속(API), 데이터를 쌓아두는 데이터베이스, 로그인 같은 인증.

← [[Web Workshop 홈]]

## 개념
- [[서버]]: 요청을 받아 처리하고 응답하는 쪽 (웹 기초 카테고리)
- [[BaaS]]: 백엔드를 직접 만들지 않고 빌려 쓰는 서비스
  - [[Supabase]]: 대표적인 오픈소스 BaaS
- [[데이터베이스]]: 데이터를 구조적으로 저장·관리하는 프로그램
- [[CRUD]]: 데이터를 다루는 네 가지 기본 동작
- [[Cloudflare R2]]: 이미지·영상 같은 파일을 저장하는 오브젝트 스토리지
