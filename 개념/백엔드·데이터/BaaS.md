# BaaS

> 백엔드를 직접 만들지 않고 이미 만들어진 걸 빌려 쓰는 서비스. Backend as a Service.

## 설명
- 보통 [[서버]]를 만들려면 데이터베이스, 로그인 인증, 파일 저장, API 서버를 하나씩 직접 짜야 한다.
- BaaS는 이 묶음을 이미 만들어서 제공한다. 가입하고 설정만 하면 바로 쓸 수 있다.
- 그래서 프론트엔드 코드만 잘 만들면, 백엔드 코드를 거의 쓰지 않고도 로그인·저장이 되는 앱을 만들 수 있다.
- 대표적인 서비스: Firebase, Supabase.

## 비유
식당을 차릴 때 주방 설비를 처음부터 만드는 대신, 이미 설비가 갖춰진 공유 주방을 빌려 쓰는 것. 요리(프론트엔드)에만 집중할 수 있다.

## 헷갈리기 쉬운 점
- BaaS는 "서버를 올려주는 곳"([[웹 호스팅]])과 다르다. 웹 호스팅은 내가 만든 서버 코드를 돌릴 공간을 빌려주는 것이고, BaaS는 서버 코드 자체를 대신 만들어서 제공하는 것이다.

## 관련 개념
