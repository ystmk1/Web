# Cloudflare R2

> Cloudflare가 제공하는 파일(이미지·영상 등) 저장소. [[데이터베이스]]처럼 구조화된 데이터가 아니라, 파일 자체를 통째로 저장하는 "오브젝트 스토리지"다.

## 설명
- 포트폴리오 사진, 영상, PDF처럼 큰 파일을 올려두고 주소로 꺼내 쓸 수 있는 저장 공간이다.
- Amazon S3와 같은 방식(S3 호환 API)으로 동작해서, S3용 코드를 거의 그대로 쓸 수 있다.
- [[BaaS]](Supabase 등)가 로그인·데이터베이스·파일저장을 묶어서 제공하는 것과 달리, R2는 "파일 저장"만 전문으로 한다.

## 무료 한도 (2026년 기준)
- 저장용량: 매달 평균 10GB까지 무료 (쌓이는 게 아니라 **매달 다시 적용되는** 한도. 10GB를 계속 보관해도 매달 무료)
- 업로드·목록조회(Class A): 월 100만 건 무료
- 읽기(Class B): 월 1,000만 건 무료
- **다운로드(egress)는 용량과 무관하게 항상 무료** — R2의 가장 큰 장점. 다른 서비스(AWS S3 등)는 보통 다운로드량에 따라 과금한다.

## 헷갈리기 쉬운 점
- "매달 10GB씩 추가"(누적)도 아니고 "평생 총합 10GB"(일회성)도 아니다. 매달 리셋되는 저장용량 한도다. 10GB 넘는 순간부터 초과분만 GB당 과금된다.
- 과금 기준은 "그 달 하루하루 저장량의 평균"(GB-month)이다. 하루만 반짝 15GB를 넘겨도 그 달 평균이 10GB를 넘으면 초과분이 과금된다.

## 웹 개발에서는
- 포트폴리오처럼 이미지·영상 미디어를 많이 쓰는 사이트에서, [[버셀]] 같은 코드 호스팅에 미디어 파일을 직접 올리는 대신 R2에 올리고 주소만 연결해서 쓴다. 코드 저장소(Git)가 무거워지는 것도 막을 수 있다.

## AWS S3·Supabase 스토리지와 다른 점
- **AWS S3와 비교**: API는 거의 똑같다(S3 호환). 가장 큰 차이는 다운로드(egress) 요금 — S3는 파일을 다운로드할 때마다 트래픽 요금이 붙지만, R2는 다운로드가 항상 무료다. 방문자가 많이 보는 미디어 사이트일수록 이 차이가 커진다.
- **CDN 측면**: R2에 올린 파일은 Cloudflare의 전세계 서버망을 그대로 타서 사용자와 가까운 곳에서 빠르게 전달된다. S3는 리전을 직접 고르고, 먼 사용자에겐 느릴 수 있다.
- **Supabase 스토리지와 비교**: Supabase 스토리지는 로그인·데이터베이스와 묶인 BaaS의 부가 기능이다. R2는 파일 저장만 전문으로 하는 독립 서비스라, 로그인·DB 없이 "미디어만" 관리할 때 더 단순하다.
