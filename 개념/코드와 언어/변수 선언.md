# 변수 선언

> JavaScript에서 값을 담을 자리(변수)를 만드는 키워드. `const`, `let`, `var` 세 가지가 있다.

## 설명
- 변수는 값을 담아두는 상자다. 상자를 만드는 방법이 세 가지다.

| 키워드 | 재할당 | 쓰는 경우 |
|---|---|---|
| `const` | 안 됨 | 기본값. 값이 바뀌지 않을 때 |
| `let` | 됨 | 값이 나중에 바뀔 걸 아는 경우 |
| `var` | 됨 | 옛날 문법. 지금은 거의 안 씀 |

```js
let count = 1;
count = 2; // 가능

const name = "민수";
name = "지수"; // 에러! const는 재할당 불가
```

## 헷갈리기 쉬운 점
- `const`로 만든 객체·배열은 **내용물을 바꾸는 건 가능**하다. 막히는 건 "변수 자체에 다른 값을 새로 넣는 것"뿐이다.

```js
const user = { name: "민수" };
user.name = "지수"; // 가능! 객체 내용 수정은 허용
user = {}; // 에러! 변수 자체를 새 값으로 바꾸는 건 안 됨
```

- `var`는 `let`·`const`보다 먼저 있던 문법인데, 범위(scope) 규칙이 헷갈리기 쉬워서 지금은 거의 안 쓴다.

## 웹 개발에서는
- 실무에서는 기본적으로 `const`를 쓰고, 값이 바뀔 걸 아는 경우에만 `let`을 쓴다.
