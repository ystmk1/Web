# Python

> 문법이 쉽고 읽기 좋은 프로그래밍 언어. AI, 데이터 분석, 자동화에서 가장 많이 쓴다.

## 설명
- 1991년에 귀도 반 로섬이 만들었다.
- 들여쓰기로 코드 구조를 나누기 때문에 영어 문장처럼 읽힌다.

```python
price = 5000
if price > 3000:
    print("비싸요")
```

- AI·데이터용 [[라이브러리]](PyTorch, pandas 등)가 압도적으로 많이 모여 있다. 그래서 다른 언어로도 AI를 할 수 있지만, 대부분 Python을 쓴다.
- 반복 작업 자동화, 웹 크롤링, 서버(Django, FastAPI)에도 쓴다.

## 비유
쉬운 말로 쓴 업무 매뉴얼. 처음 배우는 사람도 읽기 쉽다.

## 헷갈리기 쉬운 점
- Python은 브라우저에서 바로 돌지 않는다. 웹 화면을 움직이는 건 [[JavaScript]]다.
- 들여쓰기가 문법이기 때문에, 칸을 잘못 맞추면 에러가 난다.
- Python 2와 3은 서로 호환이 안 된다. 지금은 Python 3만 쓴다.

## 웹 개발에서는
- 워크숍 웹 자체는 JavaScript로 만들지만, AI 기능 서버나 데이터 처리는 Python으로 따로 만드는 경우가 많다.
- AI 에이전트가 파일 정리나 데이터 변환 같은 작업을 할 때 Python 스크립트를 자주 쓴다.
