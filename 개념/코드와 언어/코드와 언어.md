# 코드와 언어

사람이 쓰는 코드가 무엇이고, 그 코드가 CPU가 알아듣는 말로 어떻게 바뀌는지. 언어의 종류와 쓰임새.

← [[Web Workshop 홈]]

## 개념
읽는 순서대로.
- [[프로그래밍 언어]]: 사람이 컴퓨터에게 시킬 일을 적는 언어
- [[기계어]]: CPU가 바로 실행하는 0과 1의 명령
- [[컴파일러]]: 프로그래밍 언어를 기계어로 번역하는 프로그램 (인터프리터, 트랜스파일 포함)
- [[JavaScript]]: 브라우저가 실행하는 웹의 언어
- [[Python]]: AI·데이터·자동화에서 많이 쓰는 쉬운 언어
- [[리버스 엔지니어링]]: 번역을 거꾸로 거슬러 올라가 분석하는 일
