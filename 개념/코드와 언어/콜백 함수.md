# 콜백 함수

> 지금 바로 실행되지 않고, "이 일이 일어나면" 그때 실행해 달라고 다른 함수에게 넘겨주는 함수.

## 설명
- [[JavaScript]]에서 함수는 숫자나 문자열처럼 **값**이다. 변수에 담을 수도, 다른 함수의 재료(인자)로 통째로 넘길 수도 있다.
- `addEventListener("click", 콜백함수)`에서 두 번째 자리에 들어간 함수가 콜백 함수다. `"click"` 이벤트가 실제로 일어날 때까지 대기하다가, 클릭되는 순간 브라우저가 대신 호출해준다.
- 콜백은 미리 이름 붙여 만들어 둔 함수를 넘겨도 되고, 그 자리에서 바로 만든 이름 없는 함수(익명 함수)를 넘겨도 된다. 화살표 함수(`() => {}`)는 익명 함수를 짧게 쓰는 문법이다.

```js
// 1) 이름 있는 함수를 콜백으로 넘기기
function openMenu() {
  menu.open();
}
button.addEventListener("click", openMenu);

// 2) 그 자리에서 화살표 함수로 바로 넘기기 (결과는 위와 같다)
button.addEventListener("click", () => {
  menu.open();
});
```

## 비유
택배 기사에게 미리 건네는 메모. "문 앞에 도착하면 이 벨을 눌러주세요." 메모(콜백 함수)는 지금 읽는 게 아니라, 도착(이벤트)이라는 조건이 충족됐을 때 비로소 실행된다.

## 헷갈리기 쉬운 점
- `addEventListener("click", openMenu)`처럼 **함수 이름만** 넘겨야 한다. `openMenu()`처럼 괄호를 붙이면 그 즉시 실행돼 버려서, "클릭할 때"가 아니라 "코드가 이 줄을 지나가는 순간" 바로 실행된다. 콜백을 쓸 때 가장 흔한 실수다.
- 콜백 함수·화살표 함수·익명 함수는 서로 다른 개념이다. 화살표 함수는 함수를 쓰는 **문법**, 익명 함수는 "이름이 없다"는 **특징**, 콜백 함수는 "다른 함수에게 넘겨져 나중에 실행된다"는 **역할**이다. 세 가지가 한 코드에 같이 나타나는 경우가 아주 흔하다 (화살표 함수로 만든 익명 함수를 콜백으로 넘기는 것).

## 웹 개발에서는
- `addEventListener` 말고도 `fetch().then(콜백함수)`, `setTimeout(콜백함수, 시간)`처럼 "나중에 할 일"을 넘기는 곳마다 콜백 패턴이 쓰인다.
- 콜백이 중첩되면 코드가 읽기 어려워지는데("콜백 지옥"), 요즘은 `async`/`await` 문법으로 많이 대체한다.
