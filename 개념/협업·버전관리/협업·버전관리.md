# 협업·버전관리

코드의 변경 기록을 남기고 여러 명이 같이 작업하는 방법. Git, GitHub, 커밋, 브랜치, PR, 레포지토리.

← [[Web Workshop 홈]]

## 개념
읽는 순서대로.
- [[깃]]: 파일 변경 기록을 남기는 프로그램 (Git)
- [[저장소]]: 깃으로 관리하는 프로젝트 폴더 (레포지토리)
- [[커밋]]: 기록 한 칸 남기기
- [[브랜치]]: 기록을 갈래로 나누기
  - [[병합]]: 갈래를 다시 합치기 (머지)
  - [[충돌]]: 같은 곳을 다르게 고쳐서 합칠 수 없을 때
- [[깃허브]]: 깃 저장소를 올려두고 같이 쓰는 웹 서비스 (GitHub)
  - [[클론]]: 원격 저장소를 내 컴퓨터로 복사
  - [[푸시와 풀]]: 내 컴퓨터와 깃허브 사이에서 올리고 받기
  - [[풀 리퀘스트]]: 내 브랜치를 합쳐 달라는 요청 (PR)
  - [[포크]]: 남의 저장소를 내 계정으로 복사
- [[깃이그노어]]: 깃이 무시할 파일 목록 (`.gitignore`)
