# Codespace

> 깃허브가 클라우드에 띄워주는 "가상 컴퓨터 + VS Code" 개발 환경. 레포를 만들 때 뜨는 선택 옵션이지, 꼭 해야 하는 필수 단계가 아니다.

## 설명
- 로컬에 아무것도 설치하지 않아도 브라우저에서 바로 코드를 치고 실행할 수 있게 해준다.
- 깃허브 [[저장소]]를 만들면 "Create a codespace"라는 버튼이 보이지만, 이건 작업 방식을 고르는 선택지 중 하나다. 평소처럼 내 컴퓨터에서 [[클론]]해서 작업할 거면 누르지 않아도 된다.

## 언제 쓰면 좋은가
- 지금 쓰는 컴퓨터에 Node.js·Git 같은 세팅이 안 되어 있어서, 다른 기기(태블릿 등)에서 급하게 코드를 만져야 할 때.
- 여러 명이 완전히 똑같은 개발 환경에서 작업해야 할 때.

## 헷갈리기 쉬운 점
- "레포를 만들면 Codespace도 꼭 만들어야 한다"가 아니다. 레포(코드 저장 공간)와 Codespace(개발 환경)는 별개다. 레포만 만들고 로컬 VS Code + 터미널로 작업해도 전혀 문제없다.
- Codespace는 무료 사용 시간 한도가 있다(개인 계정 기준 월 단위로 제한). 계속 켜두면 한도를 넘겨 과금될 수 있다.
