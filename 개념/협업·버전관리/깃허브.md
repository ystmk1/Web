# 깃허브

> [[깃]] 저장소를 인터넷에 올려두고, 여러 명이 같이 보고 고칠 수 있게 해주는 웹 서비스.

## 설명
- 깃허브(GitHub)는 깃으로 만든 [[저장소]]를 보관하는 **온라인 창고**다. 2008년에 시작했고, 2018년에 마이크로소프트가 인수했다.
- 내 컴퓨터의 저장소를 깃허브에 [[푸시와 풀|푸시]]하면 같은 저장소가 깃허브에도 생긴다. 이것을 **원격 저장소**라고 부른다.
- 깃 기능 위에 같이 일하는 기능을 더했다.

| 기능 | 하는 일 |
|---|---|
| 원격 저장소 | 코드와 기록을 인터넷에 보관 |
| [[풀 리퀘스트]] (PR) | 내 변경을 합쳐 달라고 요청하고 리뷰 받기 |
| Issues | 할 일·버그를 글로 남기기 |
| Collaborators | 다른 사람에게 저장소 쓰기 권한 주기 |
| Actions | 올릴 때마다 검사·빌드를 자동으로 돌리기 |
| Pages | 간단한 정적 사이트를 무료로 공개 |

## 비유
깃이 내 노트북의 "세이브 기록"이라면, 깃허브는 그 기록을 올려두는 클라우드 드라이브다. 다만 그냥 드라이브와 달리, 누가 무엇을 바꿨는지 보고 의견을 달고 합치는 기능이 있다.

## 헷갈리기 쉬운 점
- 깃허브가 깃은 아니다. 깃 저장소를 올려두는 비슷한 서비스로 GitLab, Bitbucket도 있다.
- 공개(public) 저장소는 누구나 코드를 볼 수 있다. 비밀번호나 API 키가 든 `.env` 파일을 올리지 않게 [[깃이그노어]]에 적는다.
- 깃허브에 올리는 것과 사이트를 공개하는 것은 다르다. 사이트를 열려면 [[버셀]] 같은 [[웹 호스팅]]이 [[빌드]]해서 띄워야 한다.

## 웹 개발에서는
- 워크숍 협업 방식: 저장소 주인이 참여자를 Collaborator로 초대한다. 참여자는 [[브랜치]]에서 작업하고 [[풀 리퀘스트]]로 `main`에 합친다.
- [[버셀]]을 깃허브 저장소와 연결하면, 푸시할 때마다 자동으로 배포된다.
- 다른 사람의 공개 저장소를 내 계정으로 복사하는 것이 [[포크]], 내 컴퓨터로 받는 것이 [[클론]]이다.
