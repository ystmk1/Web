# 저장소

> [[깃]]으로 관리하는 프로젝트 폴더 하나. 파일과 함께 모든 변경 기록이 들어 있다.

## 설명
- 영어로 Repository, 줄여서 **레포(repo)**라고 많이 부른다.
- 보통 프로젝트 하나가 저장소 하나다. 폴더 안의 숨겨진 `.git` 폴더에 [[커밋]] 기록과 [[브랜치]] 정보가 저장된다.
- 같은 저장소가 여러 곳에 있을 수 있다.

| | 로컬 저장소 | 원격 저장소 |
|---|---|---|
| 어디에 | 내 컴퓨터 | [[깃허브]] 같은 서버 |
| 누가 씀 | 나 혼자 | 팀 전체 |
| 주고받기 | 내 작업은 여기서 먼저 기록 | [[푸시와 풀\|푸시]]로 올리고, 풀로 받는다 |
| 이름 | 내 폴더 이름 | 보통 `origin`이라는 별명으로 부른다 |

## 비유
프로젝트 전용 서랍. 파일이 들어 있고, 서랍 안쪽에는 "언제 누가 무엇을 넣고 뺐는지" 적힌 장부가 같이 있다. 깃허브에는 이 서랍의 복사본이 있어서 팀원이 같이 쓴다.

## 헷갈리기 쉬운 점
- `.git` 폴더를 지우면 파일은 남지만 기록이 전부 사라진다. 그냥 평범한 폴더가 된다.
- 저장소 안에 다른 저장소를 넣으면 꼬이기 쉽다. 프로젝트마다 저장소를 따로 둔다.
- 공개(public) 저장소와 비공개(private) 저장소가 있다. 공개 저장소는 누구나 코드를 볼 수 있다.

## 웹 개발에서는
- 새 프로젝트는 깃허브에서 저장소를 만들고 [[클론]]하거나, 내 폴더에서 `git init`을 한 뒤 깃허브에 연결한다.
- [[버셀]]은 저장소 단위로 연결한다. 저장소 하나 = 사이트 하나가 기본이다.
- 저장소 맨 위에는 보통 `README.md`(설명서)와 [[깃이그노어]](`.gitignore`)를 둔다.

## 관련 개념
- [[깃]]: 저장소를 관리하는 프로그램
- [[깃허브]]: 원격 저장소를 두는 곳
- [[클론]]: 원격 저장소를 내 컴퓨터로 복사
- [[푸시와 풀]]: 로컬과 원격 저장소 사이에서 주고받기
- [[커밋]]: 저장소에 쌓이는 기록
