# 배포

내 컴퓨터에서만 돌던 웹을 누구나 접속할 수 있게 인터넷에 올리는 과정. 빌드, 호스팅, Vercel, 도메인 연결.

← [[Web Workshop 홈]]

## 개념
- [[빌드]]: 코드를 올릴 수 있는 형태로 바꾸고 묶는 과정
- [[웹 호스팅]]: 내 사이트 파일을 24시간 켜두는 남의 컴퓨터를 빌리는 것
  - [[버셀]]: 깃허브에 푸시하면 자동으로 빌드·공개해 주는 호스팅 (Vercel)
  - [[AWS]]: 서버·저장소·DB 등을 자유롭게 조합해 쓰는 범용 클라우드 서비스
  - [[Cloudflare Workers]]: 사이트 파일과 서버 코드를 한 번에 올리는 Cloudflare 호스팅 (새 프로젝트는 Pages 대신 권장)
    - [[바인딩]]: Worker 설정에 적어 키 없이 R2·D1을 연결하는 방식
- [[CDN]]: 파일을 전 세계 거점에 미리 복사해 빠르게 받게 하는 장치
