# AWS

> 아마존이 만든 클라우드 컴퓨팅 서비스. 서버·저장공간·데이터베이스 같은 컴퓨터 자원을 필요한 만큼 빌려 쓰는 거대한 서비스 묶음.

## 설명
- [[버셀]]이 "프론트엔드 배포 한 가지"에 특화된 서비스라면, AWS는 훨씬 범용적이다.

| 서비스 | 역할 |
|---|---|
| EC2 | 가상 서버 하나를 통째로 빌림 (뭐든 직접 설치·운영) |
| S3 | 파일 저장소 (이미지, 백업 등) |
| RDS | 관리형 데이터베이스 |
| Lambda | 서버 없이 코드 조각만 실행 (서버리스) |

- 수백 개의 서비스를 레고 블록처럼 조합해서 거의 모든 걸 직접 구성할 수 있다.

## 비유
완제품 가전이 아니라 부품 매장. 버셀이 "완성된 세탁기"를 빌려준다면, AWS는 모터·드럼·전선을 따로 사서 직접 조립하는 매장에 가깝다. 자유롭지만 설정이 복잡하다.

## 헷갈리기 쉬운 점
- AWS는 "배포 서비스" 하나가 아니라 수백 개 서비스의 묶음이다. "AWS에 올린다"는 말은 그 중 뭘 쓰는지에 따라 의미가 많이 달라진다.
- 비슷한 경쟁 서비스로 Google Cloud(GCP), Microsoft Azure가 있다.

## 웹 개발에서는
- 보통 작은 프로젝트나 프론트엔드 위주 사이트는 [[버셀]]·Netlify를, 복잡한 인프라가 필요한 큰 서비스는 AWS를 쓴다.
- [[BaaS]](Firebase, Supabase)와도 다르다. BaaS는 "이미 만들어진 백엔드 기능"을 빌리는 것이고, AWS는 "컴퓨터 자원 자체"를 빌려서 직접 구성하는 것이다.

## 관련 개념

- [[웹 호스팅]]: AWS가 속하는 큰 분류
- [[BaaS]]: 자원을 직접 구성하는 AWS와 달리 기능을 통째로 빌리는 서비스
