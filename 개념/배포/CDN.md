# CDN

> 사이트 파일을 전 세계 여러 지역 서버에 미리 복사해 두는 것. 사용자는 가장 가까운 서버에서 받아서 빠르다.

## 설명
- 원본 서버가 한 곳(예: 서울)에만 있으면, 미국·유럽 사용자는 멀리까지 데이터를 받아와야 해서 느리다.
- CDN은 같은 파일을 세계 여러 거점(엣지)에 미리 복사해 둔다. 사용자는 자기와 가장 가까운 거점에서 받는다.
- 주로 이미지, CSS, JS처럼 자주 안 바뀌는 파일에 쓴다.

## 비유
전국 편의점 체인. 본사(원본 서버) 창고까지 가지 않아도, 동네 편의점(가까운 CDN 거점)에서 바로 산다.

## 웹 개발에서는
- [[버셀]] 같은 호스팅은 CDN을 기본으로 포함한다. 따로 설정 안 해도 전 세계에서 빠르게 받아진다.
- Cloudflare는 CDN·[[DNS]]를 전문으로 다루던 회사다.

## 관련 개념

- [[DNS]]: 어느 거점으로 보낼지 정하는 데도 쓰인다
- [[AWS]]: CloudFront라는 자체 CDN 서비스가 있다
