# 웹 브라우저와 웹 페이지 차이

## 질문
> 웹 브라우저와 웹 페이지의 차이, 그리고 각각 무엇인지.

## 답

### 한 줄로
[[브라우저]]는 **보는 프로그램**이고, [[웹 페이지]]는 **보이는 문서**다. 브라우저는 내 컴퓨터에 설치돼 있고, 웹 페이지는 서버에 있다가 열 때마다 받아온다.

### 비슷한 말 한꺼번에 정리
| 말 | 정체 | 어디에 있나 | 예 |
|---|---|---|---|
| 웹 브라우저 | 웹을 보는 **프로그램** | 내 컴퓨터·폰 (설치) | 크롬, 사파리, 엣지 |
| 웹 페이지 | 주소 하나로 열리는 **문서 한 장** | [[서버]] | 네이버 뉴스 기사 한 장 |
| 웹사이트 | 한 도메인 아래 모인 **웹 페이지 묶음** | 서버 | `naver.com` 전체 |
| 웹 서버 | 웹 페이지를 보내주는 **컴퓨터** | 데이터센터 | Vercel의 서버 |
| 검색엔진 | 웹 페이지를 찾아주는 **웹사이트** | 서버 | 구글, 네이버 검색 |

### 주소를 치면 일어나는 일
```
1. 브라우저 주소창에 URL 입력
2. 브라우저가 DNS로 서버의 IP 주소를 찾음
3. 브라우저가 서버에 "이 페이지 줘" 요청
4. 서버가 HTML 문서로 응답
5. 브라우저가 HTML을 읽다가 필요한 CSS·JS·이미지를 하나씩 다시 요청
6. 다 받으면 렌더링 엔진이 화면을 그리고, JS를 실행함
```

### 각각 무엇인가
- **웹 브라우저**: HTML·CSS·[[JavaScript]]를 이해하는 프로그램이다. 받은 문서를 [[렌더링 엔진]]으로 그리고, JavaScript 엔진으로 실행한다. 브라우저마다 엔진이 달라서 같은 페이지가 조금씩 다르게 보이기도 한다 → [[크로스 브라우징]]
- **웹 페이지**: HTML(구조), CSS(모양), JavaScript(동작), 이미지·폰트로 이루어진 문서다. 각 페이지에는 [[URL]]이라는 주소가 하나씩 있다.

### 비유
웹 페이지는 악보이고, 브라우저는 그 악보를 받아 연주하는 연주자다. 같은 악보라도 연주자마다 해석이 조금씩 다르다.
