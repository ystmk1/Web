# 카톡에서 이미지를 받을 때 일어나는 일

## 질문
> 요청과 응답을, 카톡에서 이미지를 다운받을 때 일어나는 일로 설명.

## 답

### 먼저: 등장인물
| 역할 | 누구 |
|---|---|
| [[클라이언트]] | 친구 폰의 카톡 앱, 내 폰의 카톡 앱 |
| [[서버]] | 카카오의 서버 컴퓨터 |

카톡은 웹 브라우저가 아니라 앱이다. 그래도 "클라이언트가 요청하고 서버가 응답한다"는 원리는 웹과 같다.

### 1단계: 친구가 사진을 보낸다 (업로드)
```
친구 폰 ──요청: "이 사진 받아줘" + 사진 데이터──▶ 카카오 서버
친구 폰 ◀──응답: "잘 받았어, 저장했어"──────────── 카카오 서버
```
- 사진은 친구 폰에서 내 폰으로 바로 가지 않는다. 먼저 카카오 서버에 올라가서 저장된다.
- 이 요청은 "새로 보내기"이기 때문에 [[HTTP 메소드]]로 치면 POST에 해당한다.

### 2단계: 내 폰이 알림을 받는다
- 카카오 서버가 내 폰에 "새 메시지가 왔어. 사진은 서버의 이 주소에 있어"라고 알려준다.
- 이때 사진 원본이 통째로 오는 게 아니다. 채팅방에는 먼저 작은 미리보기(썸네일)가 뜬다.

### 3단계: 내가 사진을 눌러서 받는다 (다운로드)
```
내 폰 ──요청: "이 주소의 사진 줘"──────▶ 카카오 서버
내 폰 ◀──응답: "200 성공" + 사진 데이터── 카카오 서버
```
- 이 요청은 "가져오기"이기 때문에 GET에 해당한다.
- 서버가 [[HTTP 상태 코드]] 200(성공)과 함께 사진 데이터를 보낸다.
- 사진 데이터는 작은 조각(패킷)으로 나뉘어 [[인터넷]]을 건너오고, 내 폰에서 다시 합쳐진다.
- 다 받으면 카톡 앱이 사진을 [[저장장치]]에 파일로 저장한다. "저장"을 누르면 갤러리에도 복사된다.

### 4단계: 시간이 지나면 "만료"
- 카카오 서버는 사진을 영원히 보관하지 않는다. 일정 기간이 지나면 서버에서 지운다.
- 그 뒤에 사진을 누르면 요청은 가지만, 서버에 줄 파일이 없다. 그래서 "기간이 만료됐다"는 안내가 뜬다. 웹으로 치면 404(없음)와 비슷한 상황이다.
- 이미 내 폰에 받아둔 사진은 내 저장장치에 있기 때문에 만료와 상관없이 볼 수 있다.

### 한 장으로
```
친구 폰 ──(업로드 POST)──▶ 카카오 서버 [사진 보관] ──(알림)──▶ 내 폰
내 폰  ──(다운로드 GET)──▶ 카카오 서버
내 폰  ◀──(200 + 사진)──── 카카오 서버
기간이 지나면: 서버에서 삭제 → 요청해도 줄 게 없음 (만료)
```

### 웹 페이지를 열 때도 똑같다
웹 페이지의 이미지도 같은 방식으로 온다. [[브라우저]]가 HTML을 받은 뒤, 안에 적힌 이미지 주소마다 GET 요청을 보내고, 서버가 200과 함께 이미지를 보낸다. 주소가 틀렸거나 이미지가 지워졌으면 404가 오고, 화면에는 깨진 이미지 아이콘이 뜬다. 처음 요청 전에는 [[DNS]]로 서버의 [[IP 주소]]를 찾는 단계가 먼저 있다.
