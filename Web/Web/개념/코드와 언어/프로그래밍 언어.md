# 프로그래밍 언어

> 사람이 컴퓨터에게 시킬 일을 사람이 읽을 수 있는 글로 적는 언어. 영어 단어와 기호로 되어 있고, 문법이 아주 엄격하다.

## 설명
- [[CPU]]는 [[기계어]]만 이해한다. 기계어는 사람이 직접 쓰기 거의 불가능하기 때문에, 사람은 쓰기 쉬운 프로그래밍 언어로 쓰고 [[컴파일러]]나 인터프리터가 기계어로 번역한다.
- 프로그래밍 언어의 핵심은 **명령과 판단**이다. "만약 ~하면 ~해라", "10번 반복해라", "이 값을 저장해라" 같은 일을 시킬 수 있다.

```js
const price = 5000;
if (price > 3000) {
  console.log("비싸요");
}
```

### 프로그래밍 언어가 아닌 것
| 이름 | 종류 | 하는 일 |
|---|---|---|
| HTML | 마크업 언어 | 내용과 구조 표시 ("이건 제목, 이건 버튼") |
| CSS | 스타일 언어 | 모양 정하기 (색, 크기, 배치) |
| JSON, YAML | 데이터 형식 | 데이터 적어두기 |
| 마크다운 | 문서 형식 | 글 서식 |

HTML과 CSS는 모양을 표시할 뿐 판단이나 반복을 하지 못하기 때문에, 보통 프로그래밍 언어로 치지 않는다.

## 비유
한국어로 쓴 레시피. 요리사(CPU)는 한국어를 모르기 때문에, 번역가(컴파일러)가 요리사가 아는 말(기계어)로 바꿔준다.

## 헷갈리기 쉬운 점
- 프로그래밍 언어 ≠ 기계어. 프로그래밍 언어는 사람용이고, 기계어는 CPU용이다.
- 코드 에디터(VS Code)는 언어가 아니라 코드를 쓰는 프로그램이다.
- Java와 JavaScript는 이름만 비슷하고 완전히 다른 언어다.
- 문법을 외우는 게 핵심이 아니다. 무엇을 어떤 순서로 시킬지 정하는 게 핵심이다.

## 웹 개발에서는
- 웹 화면을 움직이는 프로그래밍 언어는 사실상 [[JavaScript]] 하나다. HTML·CSS와 같이 쓴다.
- [[바이브코딩]]은 사람의 말을 프로그래밍 언어로 바꾸는 단계를 AI에게 맡기는 것이다. 그 아래 번역은 예전처럼 컴파일러·브라우저·OS·CPU가 한다.
