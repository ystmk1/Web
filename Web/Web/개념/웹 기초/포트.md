# 포트

> 한 컴퓨터 안에서 여러 프로그램이 동시에 통신할 수 있도록 운영체제가 나눠주는 번호표.

## 설명
- 컴퓨터 주소([[IP 주소|IP]], [[도메인]])가 건물 주소라면, 포트는 그 건물 안의 호수다. 데이터가 컴퓨터에 도착하면 포트 번호를 보고 어느 [[프로세스]]에 전달할지 정한다.
- 번호는 0~65535. 자주 쓰는 번호가 정해져 있다: 웹 [[HTTP|`http`]]는 80, `https`는 443. 그래서 평소 웹 주소에는 포트를 안 써도 된다.
- 개발용 서버는 보통 3000, 5173, 8080 같은 번호를 쓴다.

## 비유
아파트 호수. 같은 건물(컴퓨터)이라도 호수가 다르면 다른 집(프로그램)으로 택배가 간다. 한 호수에는 한 집만 살 수 있다.

## 헷갈리기 쉬운 점
- `localhost:3000`에서 `localhost`는 "내 컴퓨터", `3000`이 포트 번호다.
- 하드웨어의 USB 포트와는 다른 이야기다. 여기서 포트는 소프트웨어가 쓰는 번호.

## 웹 개발에서는
- "port 3000 already in use" = 이미 다른 프로세스가 3000번을 쓰고 있다는 뜻. 켜져 있는 다른 개발 서버를 끄거나 다른 번호를 쓰면 된다. Next.js처럼 3001로 알아서 옮겨 뜨는 도구도 있다.
- 배포된 사이트는 443(https)을 쓰니까 주소에 포트가 안 보인다.
