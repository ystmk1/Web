# 인터넷

> 전 세계 컴퓨터를 서로 연결한 거대한 통신망. 웹, 이메일, 메신저, 게임이 모두 이 망 위에서 돌아간다.

## 설명
- 1969년 미국의 ARPANET이 시작이다. 대학과 연구소의 컴퓨터를 이었다.
- 1983년에 컴퓨터끼리 데이터를 주고받는 공통 약속(TCP/IP)이 표준이 됐다. 그 덕분에 서로 다른 망들이 하나로 이어졌고, 망(net)과 망 사이(inter)라는 뜻으로 인터넷이라는 이름이 붙었다.
- 데이터는 작은 조각(패킷)으로 나뉘어 이동하고, 도착한 곳에서 다시 합쳐진다.
- 인터넷에 연결된 기기는 모두 [[IP 주소]]라는 번호를 가진다. 사람이 숫자를 외우기 어렵기 때문에 [[도메인]]이라는 이름을 쓰고, [[DNS]]가 이름을 번호로 바꿔준다.

## 비유
전 세계에 깔린 도로망. 택배(데이터)는 작은 상자(패킷) 여러 개로 나뉘어 각자 길을 찾아가고, 도착지에서 다시 하나로 합쳐진다.

## 헷갈리기 쉬운 점
- 인터넷 ≠ 웹. [[웹]]은 인터넷 위에서 돌아가는 서비스 중 하나다.
- 와이파이 ≠ 인터넷. 와이파이는 내 기기와 공유기를 무선으로 잇는 방법일 뿐이다. 공유기가 인터넷 회사의 망에 연결돼 있어야 인터넷이 된다.

## 웹 개발에서는
- `localhost`는 인터넷을 거치지 않고 내 컴퓨터 안에서만 접속하는 주소다. 그래서 다른 사람은 내 `localhost`를 볼 수 없고, 남에게 보여주려면 배포해야 한다 → [[웹 호스팅]]
- 인터넷으로 오가는 데이터는 중간에서 엿볼 수 있기 때문에, 요즘 웹은 암호화한 HTTPS를 쓴다 → [[HTTP]]
