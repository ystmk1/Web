# 웹 페이지

> 주소(URL) 하나로 열리는 웹 문서 한 장. HTML 문서와, 거기에 딸린 CSS·JavaScript·이미지로 이루어진다.

## 설명
| 재료 | 역할 |
|---|---|
| HTML | 내용과 구조 (제목, 문단, 버튼, 이미지 자리) |
| CSS | 모양 (색, 크기, 배치) |
| [[JavaScript]] | 동작 (누르면 열리기, 데이터 불러오기) |
| 이미지·폰트·영상 | HTML이 불러다 쓰는 파일 |

- [[브라우저]]는 먼저 HTML을 받고, HTML 안에 적힌 CSS·JS·이미지를 하나씩 다시 요청한다. 그래서 웹 페이지 한 장을 여는 데 [[요청과 응답]]이 수십 번 오간다.
- **웹사이트**는 한 [[도메인]] 아래 모인 웹 페이지 묶음이다. `naver.com` 전체가 웹사이트이고, 그 안의 뉴스 기사 한 장이 웹 페이지다.
- 정적 페이지는 누가 열어도 같은 내용이 나오고, 동적 페이지는 사람·시간에 따라 내용이 바뀐다(로그인한 사람의 피드 등).

## 비유
악보. 웹 페이지는 악보이고, 브라우저는 그 악보를 받아 연주하는 연주자다.

## 헷갈리기 쉬운 점
- 웹 페이지는 프로그램처럼 설치하지 않는다. 주소를 열 때마다 [[서버]]에서 받아온다.
- 웹 페이지 ≠ 웹사이트. 페이지는 한 장, 사이트는 그 묶음이다.
- 피그마나 구글 문서처럼 프로그램처럼 동작하는 웹 페이지는 "웹 앱"이라고 부른다. 원리는 같다.

## 웹 개발에서는
- 개발자 도구(F12) → Network 탭을 열고 새로고침하면, 웹 페이지 하나를 위해 오가는 요청 목록을 볼 수 있다.
- Next.js에서는 폴더·파일 하나가 페이지 하나(주소 하나)가 된다 → [[라우트]]
