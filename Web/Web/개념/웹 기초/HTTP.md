# HTTP

> 웹에서 클라이언트와 서버가 요청과 응답을 주고받는 약속(프로토콜). HyperText Transfer Protocol의 줄임말이다.

## 설명
- 팀 버너스리가 [[웹]]을 만들 때 HTML, URL과 함께 만든 세 가지 핵심 기술 중 하나다.
- 요청에는 무엇을 할지([[HTTP 메소드]]), 응답에는 결과가 어땠는지([[HTTP 상태 코드]])를 정해진 형식으로 적는다.
- **HTTPS**는 HTTP에 암호화(S = Secure)를 더한 것이다. 중간에서 누가 엿봐도 내용을 읽을 수 없다. 주소창의 자물쇠 표시가 HTTPS라는 뜻이다.
- 기본 [[포트]]는 HTTP가 80번, HTTPS가 443번이다.

## 비유
식당의 주문 규칙. "메뉴 이름 + 수량"으로 주문하고, 주방은 "나왔습니다" 또는 "품절입니다"로 답한다. 모두가 같은 규칙을 쓰기 때문에 어느 식당에서든 주문이 통한다.

## 헷갈리기 쉬운 점
- 프로토콜 = 컴퓨터끼리 정한 대화 규칙. HTTP는 웹용 규칙이고, 인터넷에는 이메일용, 파일 전송용 같은 다른 규칙도 있다.
- 요즘 사이트는 거의 다 HTTPS다. 그래서 크롬은 HTTP 사이트에 "주의 요함"을 띄운다.

## 웹 개발에서는
- 개발할 때 `http://localhost:3000`은 내 컴퓨터 안에서만 오가기 때문에 암호화가 없어도 괜찮다.
- Vercel에 배포하면 HTTPS 인증서가 자동으로 붙는다.
