# HTTP 상태 코드

> 서버가 응답할 때 붙이는 세 자리 결과 번호. 첫 자리만 봐도 성공인지, 누구 잘못인지 알 수 있다.

## 설명
| 첫 자리 | 뜻 | 자주 보는 코드 |
|---|---|---|
| **2xx** | 성공 | 200 성공, 201 새로 만들어짐 |
| **3xx** | 다른 곳으로 이동 | 301 주소가 영구히 바뀜, 304 바뀐 것 없음(저장해둔 걸 그대로 써) |
| **4xx** | 요청한 쪽(클라이언트) 문제 | 400 잘못된 요청, 401 로그인 필요, 403 권한 없음, **404 없음**, 429 요청이 너무 많음 |
| **5xx** | 서버 쪽 문제 | **500 서버 오류**, 502·504 서버끼리 연결 문제, 503 잠시 사용 불가 |

- 4xx는 "네가 잘못 달라고 했어", 5xx는 "내(서버)가 처리하다 망가졌어"라는 뜻이다.

## 비유
택배 배송 조회 결과. "배송 완료(200)", "주소지 변경됨(301)", "그런 주소 없음(404)", "택배사 사정으로 지연(500)".

## 헷갈리기 쉬운 점
- 404는 서버가 꺼졌다는 뜻이 아니다. 서버는 살아 있고, 요청한 주소에 해당하는 게 없다는 뜻이다.
- 서버가 아예 꺼져 있거나 인터넷이 끊기면 상태 코드 자체를 못 받는다. 브라우저가 "사이트에 연결할 수 없음"을 띄운다.

## 웹 개발에서는
- 에러를 만나면 첫 자리부터 본다. 4xx는 주소·로그인·입력값처럼 요청 쪽을, 5xx는 서버 코드나 서버 설정을 의심한다. AI에게 물어볼 때도 이 번호를 같이 알려주면 원인을 빨리 찾는다.
- Vercel에 배포한 사이트에서 500이 나면, Vercel 대시보드의 로그에서 서버 에러 내용을 확인한다.
- 없는 주소에 들어왔을 때 보여줄 "404 페이지"를 따로 디자인할 수 있다.
