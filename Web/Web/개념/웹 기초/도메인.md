# 도메인

> 사람이 읽고 외우기 쉽게 만든 인터넷 주소 이름. `naver.com`처럼 생겼다.

## 설명
- 컴퓨터는 [[IP 주소]](숫자)로 상대를 찾는다. 숫자는 외우기 어렵기 때문에 이름을 붙인 게 도메인이다.
- 도메인은 오른쪽부터 읽는다.

```
www . naver . com
 │      │      └─ 최상위 도메인 (.com, .kr, .co.kr, .io)
 │      └──────── 내가 등록한 이름
 └─────────────── 서브도메인 (www, blog, shop 등 마음대로)
```

- 도메인은 가비아, Namecheap, Cloudflare 같은 등록 업체에서 1년 단위로 돈을 내고 빌린다. 매년 연장하지 않으면 남에게 넘어갈 수 있다.
- 서브도메인은 도메인을 가진 사람이 공짜로 마음껏 만든다. `blog.내도메인.com`, `shop.내도메인.com`.

## 비유
건물 이름. "OO빌딩"이라고 하면 사람이 찾기 쉽지만, 실제로 찾아가려면 지번 주소(IP)가 필요하다. 이름과 지번을 이어주는 게 [[DNS]]다.

## 헷갈리기 쉬운 점
- 도메인 ≠ 호스팅. 도메인은 주소 이름만 빌린 것이고, 사이트 파일을 올려둘 서버는 따로 필요하다 → [[웹 호스팅]]
- `www`는 필수가 아니다. 서브도메인의 한 종류일 뿐이다 → [[웹]]

## 웹 개발에서는
- Vercel에 배포하면 `프로젝트이름.vercel.app` 도메인이 공짜로 나온다. 이건 Vercel 도메인의 서브도메인이다.
- 내 도메인을 쓰려면 도메인을 산 뒤, DNS 설정에서 Vercel을 가리키게 바꾼다.

## 관련 개념
- [[DNS]]: 도메인을 IP 주소로 바꾸는 시스템
- [[IP 주소]]: 도메인이 가리키는 실제 번호
- [[URL]]: 도메인이 들어가는 전체 주소
- [[웹 호스팅]]: 도메인과 짝을 이루는 서버
