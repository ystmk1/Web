# 하드웨어

> 컴퓨터에서 손으로 만질 수 있는 물리적인 부품 전부.

## 설명
컴퓨터 안의 모든 정보는 결국 전기가 흐르냐(1) 안 흐르냐(0)의 조합이다. 컴퓨터는 크게 네 가지 역할의 부품으로 일한다.

| 부품 | 역할 | 특징 |
|---|---|---|
| [[CPU]] | 명령을 실행하고 계산 | 단순한 명령을 1초에 수십억 번 |
| [[메모리]] (RAM) | 지금 작업 중인 것을 올려두는 작업대 | 빠름, 전원 끄면 사라짐 |
| [[저장장치]] (SSD) | 파일을 오래 보관하는 창고 | 상대적으로 느림, 꺼도 남아 있음 |
| 입출력 장치 | 키보드·마우스(입력), 모니터·스피커(출력), 네트워크 카드(인터넷) | 바깥과 주고받는 창구 |

그 밖에 화면을 그리는 계산을 맡는 GPU(그래픽 처리 장치)도 있다.

## 비유
주방으로 치면 주방 설비. CPU는 실제로 손을 움직이는 요리사, 메모리는 조리대, 저장장치는 냉장고·창고.

## 헷갈리기 쉬운 점
- 흔히 말하는 "용량"은 대부분 저장장치 얘기다. 폰 256GB는 저장장치, RAM 8GB는 메모리.
- 하드웨어의 반대말은 소프트웨어. [[운영체제]]와 [[프로그램]]처럼 만질 수 없는 명령의 묶음이다.

## 웹 개발에서는
- 웹사이트를 보는 내 노트북도, 웹사이트를 보내주는 서버도 결국 같은 구성의 하드웨어다. 서버는 특별한 기계라기보다 '요청에 응답하는 역할'을 맡은 컴퓨터.
- 네트워크 카드(와이파이)가 [[인터넷]]으로 데이터를 주고받는 창구다.
