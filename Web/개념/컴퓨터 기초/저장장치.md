# 저장장치

> 전원이 꺼져도 파일을 계속 보관하는 장치.

## 설명
- SSD: 반도체로 된 저장장치. 빠르고, 요즘 컴퓨터는 대부분 이것. HDD: 원판이 도는 방식. 느리지만 싸고 용량이 크다.
- 프로그램, 사진, 코드 모두 여기에 '파일' 형태로 저장된다. 파일을 폴더로 정리하는 방식(파일 시스템)은 [[운영체제]]가 관리한다.
- [[메모리]]보다 훨씬 느려서 [[CPU]]가 여기서 바로 일하지 않고, 필요한 걸 메모리로 옮겨서 쓴다.

## 비유
냉장고·창고. 많이, 오래 보관하지만 꺼내오는 데 시간이 걸린다.

## 헷갈리기 쉬운 점
- "256GB 폰"은 저장장치 용량이다. 메모리(RAM)와 다르다.
- 클라우드 저장(구글 드라이브 등)도 결국 다른 회사 서버 컴퓨터의 저장장치다.

## 웹 개발에서는
- 내가 만드는 웹사이트 프로젝트는 저장장치 안의 폴더 하나(파일 묶음)다. `node_modules` 폴더가 수백 MB씩 자리를 차지하는 것도 여기.
- 배포 = 이 파일들을 서버 컴퓨터로 옮겨서 거기서 실행되게 하는 것.
