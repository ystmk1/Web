# 네이티브 앱

> 특정 운영체제 전용으로, 그 OS가 쓰는 언어와 도구로 만든 앱. 브라우저를 거치지 않고 OS 위에서 바로 돈다.

## 설명
OS마다 프로그램이 "이것 좀 해줘" 하고 부탁하는 방법(API)이 다르다. 그래서 네이티브 앱은 OS별로 따로 만들고, OS마다 주로 쓰는 언어도 다르다.

| 플랫폼 | 주로 쓰는 언어 | 개발 도구 |
|---|---|---|
| Windows | C#, C++ | Visual Studio |
| macOS · iOS | Swift | Xcode |
| Android | Kotlin, Java | Android Studio |

- 장점: 빠르고, 카메라·알림·파일 같은 OS 기능을 깊게 쓸 수 있다.
- 단점: OS마다 따로 만들어야 하고, 앱 스토어 심사·설치가 필요하다.

## 비유
나라마다 다른 말로 쓴 안내문. 그 나라 사람에겐 가장 자연스럽지만, 나라마다 새로 써야 한다.

## 헷갈리기 쉬운 점
- 웹은 이 반대다. HTML·CSS·JavaScript는 [[브라우저]]가 이해하는 공통어라서, 브라우저만 있으면 OS와 상관없이 돈다.
  ```
  네이티브 앱:  앱 → OS → 하드웨어
  웹:          웹사이트 → 브라우저 → OS → 하드웨어
  ```
- 폰에 설치한 앱이라고 다 네이티브는 아니다. 겉은 앱인데 속은 웹 화면을 띄우는 앱도 많다.

## 웹 개발에서는
- 웹의 가장 큰 장점이 "한 번 만들면 어디서나"인 이유를 이해하는 기준점이 된다.
- 다만 웹도 결국 각 OS 위의 브라우저에서 돌기 때문에, OS 차이가 완전히 사라지지는 않는다 → [[크로스 브라우징]]
