# 리눅스

> 누구나 무료로 쓰고 고칠 수 있는 오픈소스 운영체제. 인터넷 서버 대부분이 리눅스로 돌아간다.

## 설명
- 1991년에 핀란드 대학생 리누스 토르발스가 만들기 시작했다. 지금은 전 세계 개발자와 기업이 같이 만든다.
- 코드가 공개된 [[오픈소스]]라서 누구나 가져다 고쳐 쓸 수 있다.
- 정확히 말하면 리눅스는 OS의 핵심인 **커널**의 이름이다. 이 커널에 설치 도구, 화면, 기본 프로그램을 묶은 완성품을 **배포판**이라고 한다.

| 배포판 | 특징 |
|---|---|
| Ubuntu | 가장 유명하다. 입문자에게 친절하다 |
| Debian | Ubuntu의 바탕이 된 안정적인 배포판 |
| Amazon Linux | AWS 서버용 |

### 어디서 쓰이나
| 곳 | 예 |
|---|---|
| 인터넷 서버 | 웹사이트 서버 대부분, Vercel·AWS 같은 클라우드 |
| 스마트폰 | Android의 커널이 리눅스 |
| 기기 속 | 공유기, 스마트 TV, 자동차 |
| 슈퍼컴퓨터 | 세계 상위 슈퍼컴퓨터 거의 전부 |

### 서버가 대부분 리눅스인 이유
- 무료라서 서버를 수천 대 돌려도 OS 비용이 들지 않는다.
- 화면 없이 필요한 기능만 돌릴 수 있기 때문에 가볍고, 오래 켜둬도 안정적이다.
- 서버는 보통 멀리 있어서 [[터미널]] 명령어로 관리한다. 리눅스는 원래 그렇게 쓰도록 만들어졌다.

### macOS와 닮은 이유
macOS와 리눅스는 둘 다 Unix라는 오래된 OS의 방식을 따른다. 그래서 터미널 명령어와 폴더 구조가 비슷하다. Windows는 다른 계열이라서 명령어가 많이 다르다.

```
Unix 계열: macOS, 리눅스(Ubuntu, Android 등)
다른 계열: Windows
```

## 비유
누구나 무료로 가져다 쓰는 공개 엔진. 여러 회사가 같은 엔진(커널)으로 각자 자동차(배포판)를 만든다.

## 헷갈리기 쉬운 점
- 리눅스는 한 회사의 제품이 아니다. Windows는 Microsoft, macOS는 Apple 것이지만, 리눅스는 주인이 따로 없는 공동 프로젝트다.
- 서버에는 화면이 아예 없는 경우가 많다. 마우스 대신 명령어로만 다룬다.
- 입문 단계에서 리눅스를 직접 설치할 필요는 없다.

## 웹 개발에서는
| | Windows | 리눅스 |
|---|---|---|
| 폴더 시작점 | `C:\` (드라이브 문자) | `/` 하나 |
| 파일 이름 대소문자 | 구분 안 함 | **구분함** (`Logo.png` ≠ `logo.png`) |
| 관리자 권한 | "관리자 권한으로 실행" | 명령 앞에 `sudo` |
| 프로그램 설치 | 설치 파일(.exe) | `apt install` 같은 명령 |

- Vercel에 배포하면 내 사이트는 리눅스 컴퓨터에서 빌드된다. 그래서 내 컴퓨터와 대소문자·경로 규칙이 다를 수 있다.
- **Docker**: 프로그램을 작은 리눅스 환경에 담아서 어디서든 똑같이 돌리는 도구.
- **WSL**: Windows 안에서 리눅스를 같이 돌리는 기능.
- [[Git]]도 리눅스를 만든 리누스 토르발스가 만들었다.
