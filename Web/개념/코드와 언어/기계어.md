# 기계어

> CPU가 번역 없이 바로 실행하는 명령. 0과 1(이진수)로 적혀 있다.

## 설명
- "이 숫자를 여기에 넣어", "두 숫자를 더해", "이 위치로 건너뛰어" 같은 아주 단순한 명령들이다.

```
10111000 00000101 00000000 00000000 00000000   ← 숫자 5를 꺼내 둬
```

- 사람이 이걸 직접 쓰기 어렵기 때문에, 기계어를 영어 약어로 바꿔 적은 **어셈블리어**가 있다.

```
mov eax, 5   ; 숫자 5를 꺼내 둬
add eax, 3   ; 거기에 3을 더해
```

- [[CPU]] 종류마다 알아듣는 기계어가 다르다. Intel·AMD는 x86 계열, 스마트폰과 Apple Silicon Mac은 ARM 계열이다.

## 비유
요리사(CPU)가 알아듣는 유일한 말. 아주 짧고 단순한 명령으로만 되어 있다.

## 헷갈리기 쉬운 점
- "컴퓨터 언어 = 이진수"는 반만 맞다. 이진수는 언어가 아니라 숫자를 적는 방법이다. 기계어가 이진수로 적혀 있을 뿐이고, 글자·사진·음악도 모두 이진수로 저장된다.
- 실행 파일(.exe)을 메모장으로 열면 기계어를 글자로 억지로 보여주기 때문에 알 수 없는 글자가 나온다.
- 기계어는 암호가 아니다. 사람이 읽기 어려울 뿐, 거꾸로 분석할 수 있다 → [[리버스 엔지니어링]]

## 웹 개발에서는
- CPU마다 기계어가 다르기 때문에, 같은 프로그램도 CPU별 설치 파일이 따로 있다. 그래서 다운로드할 때 Intel용과 Apple Silicon용을 고른다. Node.js를 설치할 때도 마찬가지다.
- 웹 개발자가 기계어를 직접 볼 일은 거의 없다. 브라우저가 [[JavaScript]]를 알아서 기계어로 바꿔 실행한다.
