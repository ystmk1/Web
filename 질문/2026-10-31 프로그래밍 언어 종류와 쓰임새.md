# 프로그래밍 언어 종류와 쓰임새

## 질문
> 언어의 종류와 쓰임새를 카테고리로 나눠서 간단하게. 개별 설명은 JavaScript와 Python만.

## 답

### 1. 먼저: 프로그래밍 언어가 아닌 것
| 이름 | 종류 | 하는 일 |
|---|---|---|
| HTML | 마크업 언어 | 내용과 구조 표시 |
| CSS | 스타일 언어 | 모양 정하기 |
| JSON, YAML | 데이터 형식 | 데이터 적어두기 |
| 마크다운 | 문서 형식 | 글 서식 |
| SQL | 질의 언어 | 데이터베이스에서 데이터 꺼내고 넣기. 프로그래밍 언어로 분류하기도 한다 |

### 2. 높낮이로 나누기
기계어에 가까울수록 **저수준**, 사람 말에 가까울수록 **고수준**이라고 한다.

```
저수준                                                            고수준
기계어 → 어셈블리어 → C, C++, Rust → Java, C#, Go → JavaScript, Python
```

- 저수준 언어는 빠르고 하드웨어를 세밀하게 다룰 수 있지만, 배우기 어렵다.
- 고수준 언어는 쉽고 빨리 만들 수 있지만, 상대적으로 느리다.

### 3. 번역 방식으로 나누기
| 방식 | 언어 |
|---|---|
| 미리 기계어로 컴파일 | C, C++, Rust, Go, Swift |
| 중간 코드로 컴파일한 뒤 가상 머신이 실행 | Java, Kotlin, C# |
| 실행하면서 번역 (인터프리트·JIT) | JavaScript, Python, PHP, Ruby |
| 다른 언어로 트랜스파일 | TypeScript → JavaScript |

자세한 차이는 [[컴파일러]] 참고.

### 4. 쓰임새로 나누기
| 분야 | 주로 쓰는 언어 |
|---|---|
| 웹 화면 (프론트엔드) | **JavaScript, TypeScript** (+ HTML, CSS) |
| 웹 서버 (백엔드) | JavaScript·TypeScript(Node.js), Python, Java·Kotlin, Go, PHP, Ruby, C# |
| 데이터베이스 | SQL |
| 모바일 앱 | Swift(iOS), Kotlin(Android), Dart·JavaScript(둘 다 한 번에) |
| 데이터·AI | **Python**, R, SQL |
| 게임 | C#(Unity), C++(Unreal) |
| 시스템·하드웨어 | C, C++, Rust |
| 자동화·스크립트 | Python, Bash, PowerShell |
| 데스크톱 앱 | C#(Windows), Swift(Mac), JavaScript(Electron) |

### 분야가 갈리는 이유
언어가 그 일밖에 못 해서 갈리는 게 아니다. 대부분 아래 셋 중 하나 때문이다.
- **실행되는 곳이 정해져 있다.** 브라우저는 JavaScript만 실행하기 때문에 웹 화면은 JavaScript로 만든다.
- **플랫폼 회사가 공식 언어를 정한다.** Apple은 Swift, Google은 Kotlin을 공식 언어로 민다 → [[네이티브 앱]]
- **도구가 한쪽에 쌓인다.** AI 도구가 Python에 다 모여 있기 때문에 AI는 Python으로 한다.

그래서 "어떤 언어가 최고야?"보다 "내가 만들 게 어디서 돌아가야 해?"를 먼저 정하면 언어가 거의 정해진다.

### JavaScript
브라우저가 직접 실행하는 사실상 유일한 프로그래밍 언어다. 그래서 웹 화면을 움직이려면 반드시 쓴다. Node.js 덕분에 서버에서도 돌고, 앱·데스크톱 프로그램까지 만든다. 요즘은 타입 검사를 더한 TypeScript로 쓰는 경우가 많다. 워크숍에서 쓰는 React·Next.js도 JavaScript(TypeScript)다 → [[JavaScript]]

### Python
문법이 쉽고 들여쓰기로 구조를 나누기 때문에 영어 문장처럼 읽힌다. AI·데이터 도구가 가장 많이 모여 있어서 AI, 데이터 분석, 자동화에 주로 쓴다. 브라우저에서는 돌지 않기 때문에, 웹에서는 AI 서버나 데이터 처리처럼 뒤쪽 일을 맡는다 → [[Python]]
