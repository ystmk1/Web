# 레포 주소를 로컬 폴더에 pull하고 clone해달라는 표현이 맞는지

## 질문
"(레포지토리 링크) 내 로컬 폴더(경로)에 pull하고 clone 해줘"가 AI에게 설명하기 적합한 워딩인지.

## 답
뜻은 통하지만 pull과 clone을 같이 쓰는 건 어색하다. 처음 받아오는 건 **클론 하나로 끝**이다. 클론이 파일·기록을 다 받아오고 원격 연결까지 해주기 때문에, 클론 직후에 pull할 게 없다. 순서도 "pull하고 clone"은 거꾸로다.

- 처음 받을 때: "(링크)를 (경로)에 클론해줘"
- 이미 클론한 폴더에서 새 변경 받을 때: "(경로)에서 pull해줘"

헷갈리는 지점은 **경로**다. `git clone 주소 경로`는 그 경로에 새 폴더를 만든다. 지정한 폴더가 이미 파일이 들어 있는 폴더면 클론이 거절된다. 그래서 "(경로) 안에 레포 이름으로 새 폴더 만들어서 클론해줘"처럼 어디에 폴더가 생기는지까지 말해주면 확실하다.

이미 작업한 코드가 그 폴더에 있다면 클론이 아니라 [[기존 코드에 깃 연결하기]] 상황이다.
