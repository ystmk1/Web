# 영상을 웹에 넣고 느리지 않게 최적화하는 방법

## 질문
> 영상을 웹에 넣고싶으면 어떻게해야해? 안느리게 최적화하려면 어떤 방식이 나을까?

## 답
웹에 영상을 넣는 방법은 두 가지다.
- 직접 호스팅: `<video src="...">`로 영상 파일을 사이트에 직접 올려 재생. 짧고 가벼운 배경 루프에 적합.
- 외부 서비스 임베드: YouTube·Vimeo·Cloudflare Stream 같은 전용 서비스에 올리고 `<iframe>`으로 불러오기. 긴 영상·고품질 콘텐츠에 적합.

느려지지 않게 하려면: 해상도를 낮추고 mp4로 압축해 파일을 작게 만들고, `poster` 이미지로 로드 전 썸네일을 보여주고, `preload="metadata"`와 지연 로드(lazy)로 화면에 보일 때만 받게 한다. 긴 영상은 자체 호스팅 대신 YouTube·Vimeo처럼 적응형 스트리밍을 지원하는 서비스에 올리는 게 훨씬 안 느리다.
