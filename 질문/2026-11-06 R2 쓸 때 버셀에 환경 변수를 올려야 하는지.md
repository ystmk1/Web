# R2 쓸 때 버셀에 환경 변수를 올려야 하는지

## 질문
Cloudflare R2를 쓸 때 환경 변수를 Vercel에는 안 올려도 되는지, 아니면 access 키만 올리면 되는지.

## 답
**배포된 사이트가 R2에 "쓰기"를 하느냐**로 정해진다.

| 상황 | Vercel에 넣을 것 |
|---|---|
| 사이트는 공개 주소로 이미지·영상을 보여주기만 함 | R2 키 없음. 공개 주소(`NEXT_PUBLIC_R2_URL` 등)만 선택 |
| 업로드는 내 컴퓨터(로컬 스튜디오·스크립트)에서만 | 없음. 키는 로컬 `.env`에만 |
| 배포된 사이트가 직접 업로드·삭제·목록 조회 | `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET` |
| Cloudflare Worker에서 R2 사용 | 키 없음. 바인딩으로 접근 |

- "access 키만"은 안 된다. Access Key ID와 Secret Access Key는 아이디·비밀번호처럼 **짝**이라 둘 다 있어야 동작한다.
- 비밀 키에는 `NEXT_PUBLIC_`을 붙이면 안 된다. 브라우저로 그대로 전송된다.
- 서버에 비밀 값을 덜 둘수록 안전하다. 필요 없으면 안 올리는 게 맞다.
