# 버튼 클릭 코드가 전부 함수인지

## 질문
> `button.addEventListener("click", () => { menu.open(); });` 이 코드가 전부 JS로 함수를 쓴 게 맞는지.

## 답

### 한 줄로
맞다. 이 한 줄 안에 함수가 세 번 나온다.

### 코드 뜯어보기
| 부분 | 정체 |
|---|---|
| `button.addEventListener(...)` | 함수(메서드) 호출 |
| `"click"` | 함수가 아니라 문자열. 어떤 이벤트를 들을지 적은 이름표 |
| `() => { menu.open(); }` | [[콜백 함수]]. 화살표 함수 문법으로 쓴 이름 없는 함수 |
| `menu.open()` | 콜백 함수 안에서 또 부르는 함수 호출 |

### 헷갈리기 쉬운 점
- `"click"`은 함수가 아니다. 그냥 이벤트 이름을 적은 문자열이다.
- `() => {...}`는 "지금 실행"이 아니라 "나중에 클릭되면 실행해줘"라고 넘기는 콜백이다 → [[콜백 함수]]

### 웹 개발에서는
- `button`, `menu`는 [[DOM]] 요소이거나 그 요소를 감싼 객체일 가능성이 높다. 어딘가에서 `document.querySelector` 같은 걸로 미리 찾아 뒀을 것이다.

- [[DOM]]: button·menu가 가리키는 대상
