# 레포 세팅 전에 작업한 코드를 깃에 연결하려면 뭐라고 해야 하는지

## 질문
깃허브 레포를 만들기 전에 코드 작업을 먼저 해버렸다면? 폴더부터 백업하고, 그 다음에 로컬 폴더를 기준으로 `git init`해서 push해달라고 하면 맞는 표현인지.

## 답
맞는 방향이다. 순서:
1. 폴더 통째로 복사해서 백업 (되돌릴 방법을 먼저 만들어두는 안전장치)
2. 그 폴더에서 `git init`
3. `.gitignore` 정리 → `add` → `commit`
4. 깃허브에 **완전히 빈** 저장소 생성 (README 자동 생성 체크 해제)
5. `git remote add origin` 연결 → `git push -u origin main`

AI 에이전트에게 요청할 때는 "지금 이 폴더에 있는 코드를 기준으로"라는 말을 넣어야 새 폴더를 만들지 않는다. 깃허브에서 README를 자동 생성해서 만들면 원격에 이미 커밋이 있어서 push가 거절되니, 빈 저장소로 만들거나 `--allow-unrelated-histories`로 합쳐야 한다.
