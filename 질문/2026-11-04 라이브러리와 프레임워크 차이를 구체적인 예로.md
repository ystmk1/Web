# 라이브러리와 프레임워크 차이를 구체적인 예로

## 질문
> 라이브러리는 날짜 표시 같은 기능이 필요하면 API로 가져다 쓰듯이 React 컴포넌트를 쓰는 식이고, 프레임워크는 Next.js 쓴다 치면 무슨 규칙이 있는 건지.

## 답
정확한 이해다. 핵심 차이는 **누가 누구를 부르는지**다.

- **라이브러리(React)**: 내가 필요할 때 내가 원하는 자리에서 불러다 쓴다. `useState`를 언제 어디서 쓸지는 내 코드가 정한다.
- **프레임워크(Next.js)**: 반대로 프레임워크가 내 코드를 불러 쓴다. 정해진 이름·위치에 코드를 두면, Next.js가 알아서 적절한 때 실행한다 ("제어의 역전").

Next.js의 구체적 규칙 예시: `app/about/page.tsx`를 두면 자동으로 `/about`이 됨, `app/api/.../route.ts`에서 함수 이름을 `GET`·`POST`로 지어야 요청과 자동 연결됨, `layout.tsx`·`loading.tsx`·`error.tsx` 같은 예약된 파일명이 특정 상황에 자동으로 쓰임. → [[라이브러리 vs 프레임워크]]
