# CSS Zen Garden

## 질문
> HTML 하나에 CSS 베리에이션을 엄청 많이 볼 수 있는 유명한 사이트가 뭐였는지.

## 답

### 한 줄로
**CSS Zen Garden**(`csszengarden.com`). 2003년에 데이브 샤가 만든 사이트로, 똑같은 [[HTML]] 문서 하나에 전 세계 디자이너들이 [[CSS]]만 바꿔서 완전히 다른 디자인을 만들어 올린 모음이다.

### 핵심
- 모든 디자인이 **같은 HTML**을 쓴다. 내용과 구조는 한 글자도 안 바뀐다.
- 디자인마다 완전히 다른 CSS 파일 하나만 바꿔 끼운다. 그 결과로 미니멀한 것부터 화려한 일러스트 레이아웃까지 수백 가지 모습이 나온다.
- "HTML(구조)과 CSS(모양)를 분리하면 이렇게까지 다르게 만들 수 있다"를 눈으로 보여주는 대표 사례다.

### 웹 개발에서는
- 2000년대 초반 "웹 표준" 운동 때 자주 인용됐다. 그전에는 `<font>` 태그나 인라인 스타일로 모양과 내용을 뒤섞어 쓰는 경우가 많았는데, 이 사이트가 분리의 힘을 실감 나게 보여줬다.
- 지금도 접속해서 둘러볼 수 있다. CSS 공부할 때 "같은 마크업으로 이렇게까지 다르게 만들 수 있구나"를 체감하기 좋다.

## 관련 개념
- [[CSS]]: 이 사이트가 보여주는 핵심 기술
- [[HTML]]: 모든 디자인에서 똑같이 유지되는 부분
