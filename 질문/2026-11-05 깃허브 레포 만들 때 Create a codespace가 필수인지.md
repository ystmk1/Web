# 깃허브 레포 만들 때 Create a codespace가 필수인지

## 질문
> 깃허브에서 레포 새로 만들면 create a codespace꼭 해줘야 하는거지?

## 답
아니다. 필수가 아니다. [[Codespace]]는 깃허브가 클라우드에 띄워주는 "가상 컴퓨터 + VS Code" 개발 환경으로, 레포를 만들고 나서 보여주는 선택 옵션일 뿐이다. 평소처럼 자기 컴퓨터에서 VS Code를 켜고 `git clone`해서 작업할 거라면 전혀 필요 없다. [[저장소]](레포)와 Codespace(개발 환경)는 별개의 개념이다.

## 관련 개념
- [[Codespace]]: 이 질문의 대상
- [[저장소]]: Codespace가 여는 대상이지만, 둘은 독립적이다
