# Tailwind는 클래스를 포맷처럼 제공하는지

## 질문
> tailwind는 그럼 tailwind에서 클래스를 포맷처럼 제공하는건가?

## 답

### 결론: 맞다. 단, 완성된 디자인이 아니라 낱개 규칙이다
Tailwind는 **이름과 뜻이 미리 정해진 작은 클래스 세트**를 준다. 클래스 하나가 CSS 한 줄과 같다.

| 클래스 | 실제 CSS |
|---|---|
| `px-6` | `padding-left: 24px; padding-right: 24px` |
| `py-3` | `padding-top: 12px; padding-bottom: 12px` |
| `rounded-full` | 완전히 둥근 모서리 |
| `text-white` | `color: white` |

### "포맷"보다 "사전"에 가깝다
- 이름 짓는 규칙이 있다: `속성-값` (`p`=padding, `x`=좌우, `6`=6칸).
- 숫자는 정해진 단계를 쓴다. 여백 1칸 = 4px.
- 단계에 없는 값은 `bg-[#FF3B29]`처럼 직접 적는다.
- 버튼·카드 같은 **완성 부품은 주지 않는다**. 그건 shadcn/ui, daisyUI 같은 UI 부품 라이브러리다.

### 어떻게 동작하나
빌드할 때 Tailwind가 내 파일을 훑어 **실제로 쓴 클래스만** 골라 CSS 파일로 만든다. 결과물은 결국 평범한 CSS다.

### 왜 쓰나
- 클래스 이름을 지을 필요가 없다.
- CSS 파일과 HTML을 오가지 않는다.
- 단계가 정해져 있어서 여백·색이 들쭉날쭉하지 않다.
