# 작업물 이미지·영상을 피그마에서 관리할 수 있는지

## 질문
R2·버셀·레포 클론까지 세팅한 뒤 작업을 계속 추가해야 한다. 작업별로 폴더를 나눠 원본을 저장하는 건 귀찮은데, 피그마에서 원본을 관리하는 방법은 없을까.

## 답
**된다. 이미지는 피그마를 원본 보관함으로 쓰면 된다.** 피그마는 올린 이미지의 원본을 따로 저장해 두고, [[MCP]]로 연결된 AI 에이전트가 그 원본을 꺼내 올 수 있다(Figma MCP의 `download_assets`).

### 흐름
1. 피그마에 작업 하나당 프레임 하나를 만든다. **프레임 이름 = [[slug]]** (예: `bleibtgleich`).
2. 원본 이미지를 프레임 안에 끌어다 놓는다. **레이어 이름 = 역할** (`hero`, `main`, `detail`, `ref`, `cover`, `thumb`).
3. 클로드 앱에서 시킨다: "피그마 [프레임 링크] 원본 이미지로 작업 추가해줘. 레이어 이름이 역할이야."
4. 에이전트가 할 일: 원본 다운로드 → 640·1280·2400 webp 변환 → [[Cloudflare R2]] 업로드 → 작업 JSON 작성 → [[커밋]]·[[푸시와 풀|푸시]] → [[버셀]] 자동 배포.

내가 폴더를 만들 필요가 없다. 에이전트가 `media/<slug>/`에 잠깐 받아 쓰는데, 이 폴더는 [[깃이그노어|.gitignore]]에 있어서 깃에도 안 올라간다.

### 알아둘 점
- **피그마는 긴 변 4096px까지만 보관한다.** 그보다 크면 자동으로 줄여서 저장한다. 사이트 최대 크기가 2400px라 웹용으로는 충분하다. 인쇄용 고해상도 원본이 필요하면 그건 따로(외장하드·드라이브) 보관한다.
- **크롭 여부를 말해준다.** 피그마에서 잘라 배치했다면 "프레임에 보이는 대로" 또는 "원본 그대로" 중 하나를 프롬프트에 적는다.
- **R2 키가 내 컴퓨터 `.env.local`에만 있다.** 그래서 클로드 앱 세션이 내 컴퓨터(레포 폴더)와 연결되어 있어야 업로드까지 된다. → [[2026-11-06 R2 키를 Vercel 환경 변수에 넣어야 하는 경우]]
- **영상은 예외로 둔다.** 피그마에 MP4·MOV·WebM을 올릴 수는 있지만, 영상은 용량이 커서 원본 보관함으로 쓰기 불편하다. 영상은 폴더 하나(`영상/`)에 `slug-설명.mp4`처럼 이름 규칙만 정해 모아 두거나, 긴 영상은 YouTube·Vimeo에 올려 임베드한다. → [[영상 최적화]]

### 더 간단한 대안
몇 장 안 되면 이미지를 클로드 앱 채팅창에 바로 끌어다 놓고 "이걸로 ○○ 작업 추가해줘"라고 해도 된다. 대신 배치를 눈으로 정리하려면 피그마 쪽이 편하다.

### 백업
피그마 버전 기록이 있지만, 가끔 프레임째 내보내기(export) 해 두면 안전하다.
