# 짧은 루핑 영상을 홈페이지 배경으로 쓰는 방법

## 질문
짧은 루핑 영상을 홈페이지 배경으로 쓰고 싶을 때는 어떻게 하는지.

## 답
- `<video autoplay muted loop playsinline poster aria-hidden="true">` + CSS `object-fit: cover`로 화면을 꽉 채우고 내용 뒤에 둔다.
- 첫 화면이라 lazy load는 하지 않고, 대신 파일을 더 작게: 8~15초, 소리 제거, 배경용으로 압축률을 높여 2~5MB.
- 모바일은 세로로 자른 720p 버전을 따로 쓴다.
- poster는 필수. 저전력 모드에선 자동재생이 막혀 poster만 보인다.
- `prefers-reduced-motion` 사용자에겐 poster만, 화면 밖으로 나가면 `pause()`.
- 글자를 올리면 반투명 오버레이로 대비 확보.
- 끊김 없는 루프는 편집 단계에서 끝과 시작을 맞춰 만든다.
