# React와 Next.js를 둘 다 버셀이 만들었는지

## 질문
> 리액트랑 next.js는 버셀이라는 회사가 만든거?

## 답
아니다. 둘의 제작사가 다르다.
- [[React]]: Meta(옛 Facebook)가 만들고 유지보수하는 라이브러리
- [[Next.js]]: [[버셀]]이 만든 프레임워크. React를 기반으로 라우팅·서버 기능을 더했다

그래서 버셀은 "Next.js를 만든 회사"이자 "Next.js를 가장 매끄럽게 배포할 수 있는 호스팅 서비스"다. Next.js 자체는 다른 호스팅(AWS 등)에도 올릴 수 있지만, 자기 프레임워크라 버셀이 가장 잘 지원한다.

## 관련 개념
- [[React]]: Meta가 만든 라이브러리
- [[Next.js]]: 버셀이 만든 프레임워크
- [[버셀]]: Next.js 제작사이자 대표 호스팅
