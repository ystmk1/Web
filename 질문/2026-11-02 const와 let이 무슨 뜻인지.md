# const와 let이 무슨 뜻인지

## 질문
> JS에서 const랑 let이 무슨 뜻인지.

## 답
둘 다 변수를 선언하는 키워드다. 차이는 재할당이 되는지다.
- `let`: 값을 나중에 다시 바꿀 수 있다.
- `const`: 한 번 정하면 다시 바꿀 수 없다.

### 헷갈리기 쉬운 점
`const`로 만든 객체·배열의 내용물은 바꿀 수 있다. 막히는 건 변수 자체를 새 값으로 바꾸는 것뿐이다. → [[변수 선언]]
