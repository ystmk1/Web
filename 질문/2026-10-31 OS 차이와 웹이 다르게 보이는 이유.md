# OS 차이와 웹이 다르게 보이는 이유

## 질문
> OS는 뭐고, 프로그램이 돌아가는 바닥인 OS의 차이를 이해하는 게 왜 웹 개발할 때 중요한지. OS마다 네이티브 언어도 다르고, 같은 웹을 열어도 다르게 보일 때가 있는데 그건 왜 그런지.

## 답

### OS는 프로그램이 서 있는 땅
[[운영체제]]는 하드웨어를 관리하고 프로그램들에게 나눠주는 기본 소프트웨어다. 프로그램은 하드웨어를 직접 만지지 않고 OS에게 부탁하는데, **부탁하는 방법(API)이 OS마다 다르다.** 그래서 프로그램은 OS에 맞춰 만들어진다.

### 그래서 네이티브 언어가 다르다
OS 전용으로 만든 앱을 [[네이티브 앱]]이라고 한다.

| 플랫폼 | 주로 쓰는 언어 |
|---|---|
| Windows | C#, C++ |
| macOS · iOS | Swift |
| Android | Kotlin, Java |

웹은 여기서 한 층이 더 있다. HTML·CSS·JavaScript는 [[브라우저]]가 이해하는 공통어라서, 브라우저만 있으면 OS와 상관없이 돈다. 이게 웹의 가장 큰 장점이다.

```
네이티브 앱:  앱 → OS → 하드웨어
웹:          웹사이트 → 브라우저 → OS → 하드웨어
```

### 그런데 왜 다르게 보일까
공통 무대인 브라우저가 완전히 똑같지 않고, 바닥인 OS가 군데군데 비쳐 보이기 때문이다.

1. **브라우저 엔진이 다르다**: 화면을 그리는 [[렌더링 엔진]]이 사실상 세 가지다. Chrome·Edge·삼성 인터넷은 Blink, Safari는 WebKit, Firefox는 Gecko. 같은 코드를 각자 해석해서 그린다. 아이폰에서는 애플 규정 때문에 크롬을 깔아도 속은 Safari와 같은 WebKit이라, "아이폰에서만 깨져요"는 대부분 이 차이다.
2. **폰트가 다르다 (가장 흔함)**: 웹은 기본적으로 방문자 컴퓨터에 깔린 폰트를 쓴다. 한글 기본 폰트는 Windows가 맑은 고딕, Mac·아이폰이 Apple SD 산돌고딕 Neo, 안드로이드는 기종마다 다르다. 지정한 폰트가 없으면 다른 폰트로 대체되고, 글자 폭이 달라서 줄바꿈과 레이아웃까지 바뀐다. 같은 폰트라도 Mac은 부드럽고 약간 굵게, Windows는 선명하고 얇게 그린다.
3. **기본 부품이 OS를 따라간다**: 버튼, 체크박스, 드롭다운, 날짜 선택기는 따로 디자인하지 않으면 OS·브라우저 기본 모양으로 나온다. 스크롤바도 Mac은 화면 위에 떠서 자리를 안 차지하고, Windows는 옆에 자리를 차지해서 콘텐츠 폭이 달라진다.
4. **화면 배율·해상도**: Windows 노트북은 배율이 125%·150%로 설정된 경우가 많아 전체가 크게 보이고, Mac 레티나는 픽셀이 촘촘해서 저해상도 이미지가 흐릿하게 보인다.
5. **사용자·브라우저 설정**: 다크 모드, 기본 글자 크기, 확대 비율, 광고 차단 같은 확장 프로그램, 브라우저마다 조금씩 다른 기본 스타일, 업데이트 안 한 옛 버전.

이런 차이를 감안해 어디서든 의도대로 보이게 만드는 일을 [[크로스 브라우징]]이라고 한다.

### 웹 개발할 때 OS 차이가 중요한 이유
| 단계 | OS 차이가 나타나는 곳 |
|---|---|
| 만들 때 (내 컴퓨터) | [[터미널]](PowerShell vs zsh), 경로 `\` vs `/`, 단축키 Ctrl vs Cmd, 줄바꿈 문자(Windows는 CRLF, Mac·Linux는 LF. 이 차이 때문에 Git이 "LF will be replaced by CRLF" 경고를 띄운다) |
| 올릴 때 (서버) | 서버는 대부분 [[리눅스\|Linux]] → 파일 이름 대소문자를 구분해서, 로컬에선 되는데 배포하면 이미지가 깨지는 일이 생김 |
| 볼 때 (방문자) | 방문자마다 OS·브라우저·기기가 다름 → 여러 환경에서 확인해야 함 |

### 바로 쓸 수 있는 습관
- 폰트는 웹폰트(예: Pretendard)로 지정한다
- 버튼·입력창 같은 기본 부품은 직접 스타일을 준다
- 개발자 도구의 모바일 모드는 크기만 흉내 내고 엔진은 크롬 그대로다. 아이폰 Safari는 실제 폰으로 한 번 열어본다
- 최소 확인 세트: Windows 크롬 + 아이폰 Safari
