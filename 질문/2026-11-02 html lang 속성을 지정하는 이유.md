# html lang 속성을 지정하는 이유

## 질문
> HTML head에서 lang을 지정해주는 이유가 뭔지.

## 답

### 먼저, 위치
`lang`은 `<head>` 안이 아니라 `<html lang="ko">`처럼 [[HTML]] 문서의 여는 태그 자체에 붙이는 속성이다. `<head>`보다도 앞에 나온다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  ...
</head>
```

### 한 줄로
브라우저와 보조 기술이 "이 페이지는 무슨 언어로 쓰였는지"를 미리 알게 해서, 발음·번역·검색·스타일이 올바르게 동작하게 한다.

### 지정하면 좋은 점 네 가지
| 쓰는 곳 | 안 쓰면 생기는 문제 |
|---|---|
| 스크린 리더 | 어떤 언어 음성 엔진으로 읽을지 모름. 한글을 영어 발음으로 이상하게 읽을 수 있다 |
| 브라우저 번역 기능 | "이 페이지 번역할까요?" 제안이 실제 언어와 안 맞게 뜨거나 안 뜬다 |
| 검색 엔진 | 사용자 언어에 맞는 검색 결과로 덜 노출된다 |
| CSS | `:lang()` 선택자로 동작하는 기능(따옴표 모양, 자동 하이픈 처리)이 틀어진다 |

### 헷갈리기 쉬운 점
- `lang`은 `<head>` 태그 안에 들어가는 속성이 아니다. `<html>` 태그 자체의 속성이다.
- 값은 언어 코드다. 한국어는 `ko`, 영어는 `en`, 일본어는 `ja`. 지역까지 구분하려면 `ko-KR`처럼 쓴다.
- 문서 전체가 아니라 일부분만 다른 언어면, 그 부분의 태그에 따로 `lang`을 줄 수 있다. 예: `<span lang="en">Hello</span>`

### 웹 개발에서는
- 접근성 표준(WCAG)에서 페이지 언어 표시를 지키도록 요구하는 항목 중 하나다.
- Next.js 같은 프레임워크의 기본 템플릿에는 `<html lang="en">`이 들어 있다. 한국어 사이트를 만들면 이 값을 `ko`로 바꿔야 한다. 잊기 쉬운 설정이다.
