# 개발자 종류

## 질문
> 프론트엔드·백엔드·풀스택, 퍼블리셔, 앱 개발자처럼 웹과 웹 밖의 다양한 개발자를 분류해서 정리.

## 답

### 웹 개발자
```
사용자 화면  ←  퍼블리셔 · 프론트엔드
     ↕
서버 · 데이터  ←  백엔드
     
둘 다  ←  풀스택
```

| 직군 | 하는 일 | 주로 쓰는 것 |
|---|---|---|
| 퍼블리셔 | 디자인을 HTML·CSS로 옮기는 마크업 개발자. 화면 구조와 스타일을 디자인대로 구현한다 | HTML, CSS, 약간의 JavaScript |
| 프론트엔드 개발자 | 사용자가 보고 누르는 화면과 동작을 만든다. 서버에서 받은 데이터를 화면에 보여준다 | JavaScript·TypeScript, React, Next.js |
| 백엔드 개발자 | [[서버]], 데이터베이스, 로그인, 결제, API처럼 눈에 안 보이는 쪽을 만든다 | Node.js, Python, Java·Kotlin, Go, SQL |
| 풀스택 개발자 | 프론트엔드와 백엔드를 둘 다 한다 | Next.js + 데이터베이스 같은 조합 |

### 앱 개발자
| 직군 | 하는 일 | 주로 쓰는 것 |
|---|---|---|
| iOS 개발자 | 아이폰·아이패드 앱 | Swift |
| Android 개발자 | 안드로이드 앱 | Kotlin |
| 크로스플랫폼 개발자 | 코드 하나로 iOS·Android를 동시에 | Flutter(Dart), React Native(JavaScript) |

iOS·Android 개발자처럼 한 OS 전용으로 만드는 앱을 [[네이티브 앱]]이라고 한다.

### 게임 개발자
| 직군 | 하는 일 | 주로 쓰는 것 |
|---|---|---|
| 게임 클라이언트 개발자 | 게임 화면, 조작, 물리 | Unity(C#), Unreal(C++) |
| 게임 서버 개발자 | 멀티플레이, 랭킹, 결제 | C++, C#, Go |

### 데이터·AI
| 직군 | 하는 일 | 주로 쓰는 것 |
|---|---|---|
| 데이터 분석가 | 데이터를 모아 숫자와 차트로 의사결정을 돕는다 | SQL, Python, 엑셀·BI 도구 |
| 데이터 엔지니어 | 데이터가 모이고 흐르는 길(파이프라인)을 만든다 | Python, SQL |
| 머신러닝 엔지니어 | AI 모델을 학습시키고 서비스에 붙인다 | Python, PyTorch |
| AI 엔지니어 | 이미 만든 AI 모델(API)을 써서 AI 기능이 있는 서비스를 만든다 | Python, JavaScript |
| AI 리서처 | 새로운 AI 모델과 방법을 연구한다 | Python |

### 인프라·운영
서비스가 안 꺼지고 잘 돌아가게 하는 쪽이다.

| 직군 | 하는 일 |
|---|---|
| DevOps 엔지니어 | 코드를 올리면 자동으로 테스트·배포되는 흐름을 만든다 |
| 클라우드 엔지니어 | AWS 같은 클라우드에 서버를 세우고 관리한다 |
| SRE | 서비스 장애를 막고, 장애가 나면 빨리 복구한다 |
| DBA | 데이터베이스를 관리하고 빠르게 만든다 |

이 직군은 [[리눅스]] 서버와 [[터미널]]을 가장 많이 다룬다.

### 시스템·하드웨어
| 직군 | 하는 일 | 주로 쓰는 것 |
|---|---|---|
| 임베디드 개발자 | 가전, 자동차, ESP32·아두이노 같은 기기 속 프로그램(펌웨어) | C, C++ |
| 시스템 개발자 | OS, 브라우저 엔진, 컴파일러처럼 다른 프로그램의 바탕 | C, C++, Rust |

### 보안
| 직군 | 하는 일 |
|---|---|
| 보안 엔지니어 | 서비스가 해킹당하지 않게 막는다 |
| 모의해킹 전문가 (화이트해커) | 허락받고 일부러 공격해서 약점을 찾는다 |
| 악성코드 분석가 | 악성 프로그램을 [[리버스 엔지니어링]]으로 분석한다 |

### 품질
| 직군 | 하는 일 |
|---|---|
| QA 엔지니어 | 버그를 찾고, 테스트를 자동화한다 |

### 디자인과 맞닿은 직군
| 직군 | 하는 일 |
|---|---|
| 디자인 엔지니어 (UI 엔지니어) | 디자인 감각을 갖고 화면을 직접 코드로 만든다. 인터랙션과 애니메이션에 강하다 |
| 크리에이티브 코더 | 코드로 인터랙티브 아트, 전시, 미디어 작업을 만든다 (p5.js, Three.js, TouchDesigner) |
| 테크니컬 아티스트 | 게임에서 아트와 엔진 기술 사이를 잇는다 (셰이더, 툴 제작) |

## 헷갈리기 쉬운 점
- **퍼블리셔는 한국에서 주로 쓰는 직군 이름이다.** 해외에서는 따로 나누지 않고 프론트엔드 개발자가 이 일까지 한다. 국내에서도 점점 프론트엔드로 합쳐지는 추세다.
- 직군 경계는 회사마다 다르다. 같은 일을 하는데 이름이 다르거나, 한 사람이 여러 역할을 맡기도 한다.
- "웹 개발자"는 넓은 말이다. 보통 프론트엔드·백엔드·풀스택 중 하나를 가리킨다.

## 웹 워크숍 기준으로는
- 워크숍 참가자는 Next.js로 화면과 간단한 서버를 같이 만들고 Vercel로 배포한다. 작은 규모의 풀스택 흐름을 한 번 겪어보는 셈이다.
- 바이브코딩에서는 AI가 여러 직군의 일을 대신해 준다. 그래서 각 직군이 무슨 일을 하는지 알면 AI에게 "프론트엔드 쪽 문제야", "서버 쪽 문제야"처럼 정확하게 물어볼 수 있다.
