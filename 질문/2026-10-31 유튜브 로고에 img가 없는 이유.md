# 유튜브 로고에 img가 없는 이유

## 질문
> 유튜브(모바일 웹)에서 로고를 검사했는데 Elements에 `<img>`가 없다. 왜 없는지.

## 답

### 한 줄로
유튜브 로고는 이미지 파일이 아니라 [[SVG]] 코드로 HTML 안에 직접 들어가 있기 때문에 `<img>`가 없다.

### 구조
```
<ytm-home-logo>
  <button aria-label="YouTube 홈">
    <c3-icon>
      <span class="yt-icon-shape">
        <div style="... fill: currentcolor;">
          <svg> <path d="M..."/> </svg>   ← 여기가 로고
```
- `<div>` 앞의 ▶를 펼치면 `<svg>`와 `<path>`가 나온다.
- `fill: currentcolor`는 로고가 글자색을 따라가라는 뜻이다. 그래서 다크 모드에서 YouTube 글자가 흰색으로 바뀐다.

### 유튜브가 SVG를 쓰는 이유
- 확대해도 깨지지 않는다.
- HTML과 같이 오기 때문에 이미지 파일을 따로 요청하지 않는다.
- CSS로 색을 바꿀 수 있어서 다크 모드 대응이 쉽다.

### 그림인데 img가 아닌 경우들
| 정체 | Elements에서 보이는 모습 |
|---|---|
| 인라인 SVG | `<svg>` · `<path>` |
| CSS 배경 이미지 | 빈 `<div>` · Styles에 `background-image: url(...)` |
| 반응형 이미지 | `<picture>` 안의 `<source>` + `<img>` |
| 캔버스 | `<canvas>` (속이 안 보임) |

### 시연에서 바꾸려면
1. 색 바꾸기: 그 `<div>`를 고르고 Styles의 element.style에 `color: red`를 추가한다. currentcolor 부분이 빨간색이 된다.
2. 그림 바꾸기: `<div>`에 우클릭 → Edit as HTML(HTML로 수정) → 안의 `<svg>…</svg>`를 지우고 `<img src="이미지 주소" style="height:100%">`를 넣는다.
3. 지우기: `<svg>`를 고르고 Delete.
