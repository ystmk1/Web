# 프로그래밍 언어와 기계어 차이

## 질문
> 프로그래밍 언어란 뭔지. 흔히 혼동하는 "프로그래밍 언어 ≠ 기계어"를 중심으로.

## 답

### 한눈에 보기
```
사람이 쓰는 코드:     console.log("안녕")      ← 프로그래밍 언어
번역하는 프로그램:    컴파일러 / 인터프리터     ← 번역가
CPU가 실행하는 명령:  10111000 00000101 ...    ← 기계어
```

| | [[프로그래밍 언어]] | [[기계어]] |
|---|---|---|
| 누가 읽나 | 사람 | [[CPU]] |
| 생김새 | 영어 단어와 기호 | 0과 1 |
| 예 | JavaScript, Python | `10111000 00000101` |
| CPU가 바뀌면 | 같은 코드를 쓰고 번역만 다시 한다 | CPU 종류마다 다르다 |

### 둘이 따로 있는 이유
CPU는 아주 단순한 명령만 이해한다. 그래서 "버튼을 누르면 메뉴를 열어라"를 기계어로 쓰면 수백 줄의 0과 1이 되고, 사람이 그걸 직접 쓰기는 불가능하다. 이런 이유로 사람은 쓰기 쉬운 프로그래밍 언어로 쓰고, 번역은 프로그램([[컴파일러]]·인터프리터)에 맡긴다.

### 자주 혼동하는 말
| 이렇게 말하면 | 실제로는 |
|---|---|
| "프로그래밍 언어 = 컴퓨터가 쓰는 말" | 컴퓨터(CPU)가 쓰는 말은 기계어다. 프로그래밍 언어는 사람이 쓰는 말이다 |
| "컴퓨터는 이진수라는 언어를 쓴다" | 이진수는 숫자를 적는 방법이다. 기계어가 이진수로 적혀 있을 뿐이다 |
| "HTML도 코딩 언어지?" | 마크업 언어다. 프로그래밍 언어가 아니다 |
| "VS Code가 컴파일해준다" | VS Code는 에디터다. 번역은 컴파일러나 브라우저가 한다 |
| "컴파일된 프로그램은 암호화된 것" | 번역된 것이다. 이름과 주석이 사라졌을 뿐이라 거꾸로 분석할 수 있다 → [[리버스 엔지니어링]] |

### 바이브코딩과 연결하면
```
1. 사람의 말         "버튼 누르면 메뉴 열어줘"
   ↓ AI가 번역 (바이브코딩)
2. 프로그래밍 언어    JavaScript 코드
   ↓ 브라우저 엔진이 번역
3. 기계어            CPU 명령
```

[[바이브코딩]]은 1번에서 2번으로 가는 번역을 AI에게 맡기는 것이다. 2번에서 3번은 예전처럼 컴파일러와 브라우저가 한다.
