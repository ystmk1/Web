# 이미지를 git에 넣는 것보다 R2 링크로 관리하는 게 좋은 점

## 질문
이미지를 깃 저장소에 넣고 같이 호스팅하는 것보다, Cloudflare R2에 올리고 링크로 관리하는 게 뭐가 좋은지.

## 답
- **저장소가 안 무거워진다.** 깃은 모든 버전을 기록하므로 이미지를 넣으면 지워도 과거 기록에 남는다. 사진을 바꿀 때마다 저장소가 커지고 클론·푸시가 느려진다.
- **교체가 쉽다.** R2는 같은 이름으로 덮어쓰면 끝. 깃은 바꿀 때마다 새 기록이 쌓인다.
- **배포가 빠르다.** 코드만 빌드·업로드하면 된다.
- **트래픽이 무료다.** 깃에 넣으면 버셀 같은 호스팅의 무료 전송량을 쓰고, R2는 다운로드가 항상 무료다.
- **영상·큰 파일이 가능하다.** 깃허브는 파일당 100MB 제한이 있다.
- **어디서든 재사용.** 주소만 있으면 다른 사이트·문서에서도 같은 파일을 쓴다.

단점도 있다: 버킷·공개 주소·`next.config` 도메인 등록 같은 세팅이 더 필요하고, 파일 이름을 바꾸면 링크가 깨지며, 이미지 버전 기록은 없다.

**작은 사이트(압축 이미지 몇십 장)면 깃에 넣어도 충분하다.** 사진·영상이 계속 늘어나는 아카이브형 포트폴리오일수록 R2가 유리하다.
