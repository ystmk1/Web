# 패키지는 프로젝트마다 설치하는지 컴퓨터에 한번 설치하면 계속 쓰는지

## 질문
> 프로젝트별로 설치하는 건지, 컴퓨터에 한 번 설치하면 계속 쓸 수 있는 건지 궁금.

## 답
**프로젝트별로 설치**된다. 두 층이 나뉜다.

- [[Node.js]], npm: 컴퓨터에 한 번만 설치 (전역)
- [[React]] 같은 패키지: 프로젝트마다 각각 설치 → [[node_modules]]

프로젝트마다 React 버전이 달라도 되고, 다른 사람이 프로젝트를 받았을 때 `npm install` 한 번이면 `package.json`에 적힌 버전 그대로 설치된다. 그래서 새 프로젝트를 만들 때마다 패키지가 그 프로젝트 폴더 안에 다시 설치된다.

## 관련 개념
- [[node_modules]]: 패키지가 실제로 저장되는 프로젝트별 폴더
- [[Node.js]]: 전역으로 한 번만 설치하는 실행 환경
