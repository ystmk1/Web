# JS를 품은 HTML 같은 문법과 그걸 묶어주는 도구가 뭔지

## 질문
"JS를 품은 HTML 언어", "패키징 엔진" 같은 게 있었는데 그게 뭔지.

## 답
세 가지가 섞여 기억되기 쉽다.

| 이름 | 정체 | 생김새 |
|---|---|---|
| [[JSX·TSX\|JSX]] | JS 파일 안에 HTML처럼 생긴 태그를 쓰는 **문법** (React) | `return <h1>{title}</h1>` |
| 번들러·트랜스파일러 | JSX를 브라우저가 읽는 JS로 **번역**하고 여러 파일을 **묶는** 도구 ("패키징"에 해당) | [[Vite]], Webpack, Babel, esbuild |
| 템플릿 엔진 | **HTML 파일 안에** JS(또는 다른 언어) 조각을 끼워 서버가 값을 채우는 방식 | EJS의 `<h1><%= title %></h1>` |

- 이름에 "엔진"이 붙는 건 템플릿 엔진이다. "패키징"이라고 기억했다면 번들러다.
- JSX는 언어가 아니라 JavaScript의 확장 문법이다. 브라우저는 JSX를 직접 못 읽어서 빌드 때 일반 JS(`React.createElement(...)` 같은 호출)로 바뀐다.
