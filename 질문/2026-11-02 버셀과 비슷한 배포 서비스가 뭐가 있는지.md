# 버셀과 비슷한 배포 서비스가 뭐가 있는지

## 질문
> Vercel이 뭐고, 비슷한 서비스는 또 뭐가 있는지.

## 답

### Vercel이란
[[버셀]]은 깃허브에 코드를 푸시하면 자동으로 빌드하고 배포해주는 호스팅 서비스다. Next.js를 만든 회사라서 Next.js 배포에 특히 최적화되어 있다.

### 비슷한 서비스
| 서비스 | 특징 |
|---|---|
| Netlify | 버셀과 거의 같은 포지션. Git 연동 자동 배포, 정적 사이트·React에 강함 |
| Cloudflare Pages | Cloudflare의 프론트엔드 배포 서비스. 엣지망이라 전 세계에서 빠르고, 무료 할당량이 넉넉함 |
| GitHub Pages | 깃허브 자체 제공 무료 호스팅. 정적 사이트만 가능 (서버 기능 없음) |
| Render | 프론트엔드뿐 아니라 백엔드 서버·데이터베이스까지 올릴 수 있는 더 범용적인 호스팅 |

버셀·Netlify·Cloudflare Pages는 "프론트엔드 올리기"에 특화되어 있고, Render 쪽은 서버까지 통째로 돌리는 더 넓은 용도다.
