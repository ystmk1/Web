# Next.js가 뭔지

## 질문
> Next.js는 뭐야?

## 답
[[Next.js]]는 [[React]]를 기반으로 실제 서비스를 만들기 좋게 기능을 더한 프레임워크다. React는 화면 그리기만 담당하는 라이브러리라서, 주소별 페이지 나누기·서버 기능·성능 최적화는 직접 짜야 한다. Next.js는 이걸 기본으로 갖추고 있다.

### 핵심 기능
- 파일 기반 라우팅: `app/` 폴더 구조 = URL 구조
- 서버 기능: `app/api/`에서 백엔드 코드도 같은 프로젝트에서 작성
- 빌드·최적화 자동화
- [[버셀]]과 궁합이 좋음 (같은 회사)
