# Vite 같은 빌드 도구도 프레임워크인지

## 질문
> Vite 같은 빌드 방식도 프레임워크인가?

## 답
아니다. [[Vite]]는 **빌드 도구**다. [[라이브러리 vs 프레임워크]]에서 말하는 "제어의 역전" 같은 규칙이 없다.

Vite는 화면을 어떻게 구성할지엔 관여하지 않는다. React든 Vue든, 그 코드를 빠르게 묶고 실행해 주는 도구일 뿐이라 보통 라이브러리와 짝지어 쓴다("Vite + React").

| 분류 | 역할 | 예 |
|---|---|---|
| 빌드 도구 | 코드를 묶고 실행 준비 | Vite, Webpack |
| 라이브러리 | 화면을 어떻게 만들지 (내가 호출) | React |
| 프레임워크 | 코드 구조·규칙까지 정함 (저쪽이 호출) | Next.js |

[[Next.js]]는 자체 빌드 시스템을 이미 포함하고 있어서 Vite를 따로 안 쓴다. Vite는 "프레임워크 없이 React만 가볍게 쓰고 싶을 때" 주로 선택한다.
