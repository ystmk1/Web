# rem 나오기 전엔 em을 썼는지

## 질문
> rem이 나오기 전, 옛날에는 em을 썼는지.

## 답

### 한 줄로
썼다. `em`이 먼저고 [[rem]]이 나중이다. `em`은 CSS 1996년 첫 버전부터 있었고, `rem`은 2010~2012년쯤 돼서야 여러 브라우저가 제대로 지원했다.

### rem 없던 시절(2000년대)에 쓰던 두 방법
| 방법 | 내용 |
|---|---|
| `em` | 중첩될수록 크기가 겹겹이 쌓이는 단점을 알면서도 널리 썼다 |
| 62.5% 트릭 | `body { font-size: 62.5%; }`로 먼저 깔아 `1em = 10px`로 맞춰 암산을 쉽게 만드는 편법 |

### 왜 하필 em이었나
- 그 시절 IE6은 `px`로 쓴 글자 크기를 사용자가 브라우저에서 키울 수 없는 버그가 있었다. `em`이나 `%`로 쓴 글자는 키울 수 있었다.
- 그래서 "접근성을 생각하면 `px` 대신 `em`을 써라"가 2000년대 초반 웹 표준 운동의 정석이었다.

### 지금은
`rem`이 웬만한 브라우저에서 다 되기 시작한 뒤로(2012년 즈음부터)는 역할을 나눠 쓴다. 전체 크기 기준은 `rem`, 버튼 안 여백처럼 자기 글자 크기에 비례해야 하는 곳은 `em`.

## 관련 개념
- [[rem]]: em의 겹침 문제를 해결하려고 나온 단위
