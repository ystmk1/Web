# 개발이 OS에 받는 영향

## 질문
> 개발은 OS에 굉장히 큰 영향을 받지?

## 답

### 결론: 무엇을 만드느냐에 따라 다르다
OS 영향은 두 군데서 따로 온다.

1. **어디서 돌아가나 (실행 OS)**: 완성된 프로그램이 돌아갈 곳
2. **어디서 만드나 (개발 OS)**: 내가 코드를 쓰고 실행하는 컴퓨터

실행 OS가 정해진 프로그램은 영향을 크게 받는다. 웹은 브라우저가 OS를 가려 주어서 영향이 작다.

### 만드는 것별 영향
| 만드는 것 | 영향 | 이유 |
|---|---|---|
| 웹 프론트엔드 | 작음 | 브라우저가 공통 무대. 같은 코드가 Windows·Mac·폰에서 돈다 |
| 웹 백엔드 | 중간 | 서버는 대부분 [[리눅스\|Linux]]. 내 컴퓨터와 서버의 차이를 맞춰야 한다 |
| iOS · macOS 앱 | 큼 | 공식 도구 Xcode가 macOS에서만 돈다. 그래서 Mac이 필요하다 |
| Android 앱 | 작음 | Android Studio가 Windows·Mac·Linux에서 모두 돈다 |
| Windows 앱 | 큼 | Windows 전용 기능을 쓰면 Windows에서 만들고 시험해야 한다 |
| 게임 | 중간~큼 | 그래픽 기술과 콘솔 개발 도구가 플랫폼마다 다르다 |

### 웹을 만들어도 OS가 보이는 곳
코드는 같아도 **만드는 과정**에서 OS 차이가 나온다.

- 터미널 명령어: PowerShell과 zsh는 명령어가 조금 다르다
- 경로: Windows는 `\`, Mac·Linux는 `/`
- 파일 이름 대소문자: Windows·Mac은 기본으로 구분하지 않고, Linux 서버는 구분한다. 그래서 내 컴퓨터에선 되는데 배포하면 이미지가 깨진다
- 설치·권한 에러: [[PATH]], 스크립트 실행 차단 같은 문제
- 화면: 폰트·스크롤바가 OS를 따라가서 조금 다르게 보인다 → [[크로스 브라우징]]

### 바이브코딩에서 실제로 쓰는 판단
- **웹만 만든다면**: 가진 컴퓨터 아무거나 써도 된다. Windows도 충분하다
- **에러가 나면**: 먼저 "코드 문제인가, 내 OS 환경 문제인가"를 나눈다. AI에게 물을 때 OS 이름을 같이 적으면 답이 정확해진다
- **아이폰 앱까지 만든다면**: 보통 Mac이 필요하다. Expo 같은 도구는 클라우드의 Mac에서 iOS 빌드를 대신 해 주지만, 시험과 세부 설정은 Mac이 있으면 편하다
