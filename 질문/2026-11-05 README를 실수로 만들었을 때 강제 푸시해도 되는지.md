# README를 실수로 만들었을 때 강제 푸시해도 되는지

## 질문
로컬 코드를 올리려고 빈 레포를 만들려 했는데 실수로 README를 체크해서 만들었다. 그냥 강제 푸시(하드 푸시)해도 되는지. 그리고 처음의 `git init`은 내 로컬 폴더에 깃 환경을 세팅하는 게 맞는지.

## 답
- **강제 푸시해도 된다.** 원격에 있는 건 README 커밋 하나뿐이고 혼자 쓰는 새 레포라, 덮어써도 사라지는 건 그 README뿐이다. 명령은 `git push -f origin main` (조금 더 안전한 `--force-with-lease`도 있다).
- 다른 방법: README를 살리고 싶으면 `git pull origin main --allow-unrelated-histories`로 합친 뒤 푸시. 아예 레포를 지우고 빈 레포로 다시 만들어도 된다.
- **협업 레포에서는 강제 푸시 금지.** 남이 올린 커밋까지 지워진다.
- `git init`은 대체로 맞는 이해다. 정확히는 깃을 설치하는 게 아니라, 이미 설치된 깃이 이 폴더의 변경을 기록하도록 `.git` 폴더(기록 장부)를 만드는 것이다. 커밋 작성자 이름·이메일 설정(`git config`)은 별개다.
