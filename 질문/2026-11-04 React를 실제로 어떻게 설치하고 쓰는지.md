# React를 실제로 어떻게 설치하고 쓰는지

## 질문
> React는 어떻게 사용해? 초기에 React 사용한다고 설명해두고 React 코드를 사용하는 건가?

## 답
"React 쓸게요"라고 따로 선언하는 과정은 없다. **프로젝트를 만들 때 설치되고, 필요할 때 import해서 쓰는** 방식이다.

1. **프로젝트 생성 시 자동 설치**: `npx create-next-app` 또는 `npm create vite -- --template react`를 실행하면 `package.json`에 React가 의존성으로 추가된다. 이게 "이 프로젝트는 React를 쓴다"는 선언에 가장 가깝다.
2. **`.jsx`/`.tsx` 파일에서 [[JSX·TSX]] 문법 사용**: 확장자가 이거면 [[빌드]] 도구가 JSX를 자동으로 React 코드로 변환한다. 요즘은 파일마다 `import React`를 따로 안 써도 된다.
3. **필요한 기능만 import**: `import { useState } from 'react'`처럼 쓰는 훅만 가져온다.
4. **컴포넌트를 만들어 다른 파일에서 또 가져다 씀**: `import Button from './Button'`.

즉, 선언은 프로젝트 생성 시점 한 번뿐이고, 이후는 필요한 컴포넌트·기능을 조립하는 식이다.
