# DOM이 브라우저가 만든 요소 목록인지

## 질문
> DOM: 브라우저가 HTML을 읽어서 만든 요소 목록인 거지.

## 답
맞다. 더 정확히는 브라우저가 HTML을 읽어서 메모리에 만든, **트리(나무) 모양의 객체**다. "요소 목록"도 틀린 건 아니지만, 일렬로 나열된 목록이 아니라 부모-자식 관계로 중첩된 구조라는 점이 핵심이다.

```
body
├─ h1
└─ p
```

JS는 이 구조를 따라가며("이 요소 안의 자식들") 요소를 찾고 바꿀 수 있다. → [[DOM]]
